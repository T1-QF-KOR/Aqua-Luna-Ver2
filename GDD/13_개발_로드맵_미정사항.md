# 13. 미정 사항과 후속 작업

[전체 GDD 목차](README.md) · 기준일 2026-10-07 · v0.1

아래 순서는 **GDD 정리 시 제안하는 논의 순서**이며, 확정된 개발 일정이나 추가 기능 약속은 아니다.

| 우선순위 | 결정 / 검증할 내용 | 필요한 결과 |
| --- | --- | --- |
| 1 | 대학 시절의 정확한 학과·학년·연도·나이·말투와 본편 연결 | 같은 전공·같은 학년의 대학 친구는 사용자 확정. [대학편 초안](17_대학시절_스토리라인.md)의 문화콘텐츠학과·2학년 1학기 등 집필 가안 검토 |
| 2 | 목표 이용자·이용등급 목표·대표 플레이 길이 | 누구에게 어떤 분량의 경험을 제공할지 기준 |
| 3 | 30시간 목표와 반복 체험의 재미 | 규칙·난도별 소요시간, 힌트 사용률, 반복 피로, 중도 이탈 기록 |
| 4 | 수입·가격·기력의 장기 밸런스 | 무료 관계 경로와 전체 탐방 경로에서 필요한 노동·반복량 평가 |
| 5 | 이야기 개별성과 연인·친구 후속 표현 | 공통 장면 반복, 관계별 문구의 일관성 검토 |
| 6 | 장소별 배경·추가 표정·음원·보이스 범위 | 제작 목록과 우선순위 결정 |
| 7 | 대상 브라우저·기기와 접근성 | 실제 기기, 키보드, 스크린리더, 글자 확대, 음향 확인 |
| 8 | 배포·수익화·출시 범위 | 배포 형식과 출시 완료 조건 결정 |

신규 구상은 먼저 이 표 또는 관련 상세 기획에 기록한다. 구현 후에는 규칙·콘텐츠 집계·검증 근거를 함께 갱신하고, 미확정 제안을 구현 사실로 표현하지 않는다.
