# 16. QA와 검증 기준

[전체 GDD 목차](README.md) · 기준일 2026-10-07 · v0.1

## 검증 원칙과 현재 근거

이 GDD는 기존 구현과 기록을 정리한 문서다. 과거의 테스트 통과를 이번 작업에서 재실행한 결과로 표현하지 않는다. 코드에서 확인한 동작, 기존 자동 검사, 실제 사람의 사용성 평가는 구분한다.

| 영역 | 테스트 진입점 | 확인할 핵심 |
| --- | --- | --- |
| 경제·행동 | [runner.html](../tests/runner.html) | 수입·지출 등식, 행동 제한, 실패 시 무변경, 자원 상한 |
| 관계·서사 | [story.html](../tests/story.html) | 무료 경로, 연인·친구·보류, 갈등 회복, 대화 중 저장, 중복 정산 방지 |
| 전체 탐방 | [courses.html](../tests/courses.html) | 48곳 조건, 후속 이야기, 양쪽 관계에서 마지막 사건 도달, 첫 기억 유지 |
| 체험 | [activities.html](../tests/activities.html) | 576판 해결 가능성, 단계 해금, 힌트·되돌리기·저장·조작 기록 검증 |
| 기본 UI | [ui.html](../tests/ui.html) | 새 게임부터 활동·저장·불러오기까지 주요 경로 |
| 관계 UI | [story-ui.html](../tests/story-ui.html) | 대화 선택과 응답·결과·재개·회상 |
| 탐방 UI | [courses-ui.html](../tests/courses-ui.html) | 필터·페이지·출발·방문 수첩 |
| 체험 UI | [activities-ui.html](../tests/activities-ui.html) | 실제 입력·중간 저장·PC 화면 |
| 의상 | [wardrobe.html](../tests/wardrobe.html), [fashion.html](../tests/fashion.html) | 보유·착용·소품 호환·취소·앨범 코디 보존·이미지 표시 |
| 저장 장애 | [reliability.html](../tests/reliability.html) | localStorage 실패, 백업, 손상 파일, 비동기 가져오기 취소 |
| 브라우저 통합 | [run-story-check.ps1](../tests/run-story-check.ps1), [browser-check.ps1](../tests/browser-check.ps1) | 전용 테스트 프로필, 실제 키 입력·다운로드·새로고침 |

PowerShell 자동화는 기존 Windows 검증 환경의 스크립트다. 현재 환경에서 그대로 실행 가능하다고 전제하지 않는다.

## 기존 정량 기록

- [체험 감사](../qa/activity-audit.json): 생성형 576판, 규칙별 192판, 해결 가능 검사 결과와 사람 30시간 미검증 상태.
- [대본 감사](../qa/course-content-audit.json): 51코스, 35편, 선택 장면 360개, 중복 제거 본문 232개, 중복 제거 문자 수 26,600자.
- [최신 과거편 보고서](../reports/PREQUEL_EXPANSION_2026-10-07.md): 전체 루트·저장 검사 범위와 제한. 모바일 지원 제거 전의 과거 기록이다.
- [과거 검증 기록](../reports/QA_REPORT.md): 초기 경제·저장·그림 검사. 본문의 과거 미구현 설명은 작성 시점에 한정한다.

장면·문자 수는 전체 분기를 합한 감사 값이며 한 경로의 독서시간과 같지 않다. 이번 GDD 작성에서 콘텐츠 수량은 현재 정의를 로드해 재확인했다. 해결 가능성과 장기 플레이는 재실행하지 않았다.

## 후속 출시 평가 항목

- [ ] 새 게임부터 연인·친구 후일담과 탐방 마지막 이야기까지 실제 사람이 플레이한다.
- [ ] 보류·갈등 회복·저장 재개 경로에서 서사 모순을 확인한다.
- [ ] 퍼즐 난도별 소요시간, 힌트 사용, 반복 피로를 기록해 30시간 목표를 판단한다.
- [ ] 경제 행동 반복량과 후반 관계 수치 상한의 영향을 평가한다.
- [ ] PC 대상 브라우저(Chrome·Edge)에서 1280 × 720, 1440 × 900, 1920 × 1080 화면을 검증한다.
- [ ] 키보드만 사용, 글자 확대, 스크린리더, 동작 줄이기 설정을 확인한다.
- [ ] 합성 배경음을 직접 듣고 음량·장시간 피로도를 확인한다.
- [ ] 폰트·그림·원작 참조의 배포 출처 기록을 정리한다.

위 항목은 새로 통과했다고 표시한 검사가 아니라 남은 완료 기준이다.
