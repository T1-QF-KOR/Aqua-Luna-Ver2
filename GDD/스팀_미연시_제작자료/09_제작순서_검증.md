# 제작 순서와 검증 기준

[목차](README.md) · 구현 계획은 제안이며 이번 문서 작성 중 게임을 제작하지 않았다.

## 첫 검증 범위

| 묶음 | 검증 내용 | 수량/상태 |
| --- | --- | --- |
| 첫날 | 3/2 자취방·민재·지난 방송 | 현재 장면표에 맞춰 연결 |
| 만남 | 나리의 한 첫 만남 경로, 다은 새터, 서진 첫 출근 | 대표 경로로 먼저 시험. 나머지 나리 변형·대체는 다음 단계에서 필수 보완 |
| 개인 활동 | ACT-01 멜로디의 한 버전 | 선택·기록·공유 확인 |
| 대표 방송 | 4/2 첫 방송과 ACT-02 사연 화면 | 해당 날짜의 조건을 정확히 재현. 3월 첫 주에 방송을 앞당기지 않음 |
| 기록 | 실제 만남·멜로디 공유·청취 | 사용자에게 알 수 있는 것만 표시 |
| 선택 | 4칸 일정과 실제 위치에 따른 인물 선택 | 만남·비용·시간의 충돌 없이 동작 |
| 저장 | 개인 활동·대화·방송 중 저장 및 재개 | 비용·보상 중복 없이 복원 |

나리 대체 첫 만남을 포함한 전체 루트, 세 사람의 고백·교차·결말은 초반 검증 후 GDD대로 확장한다. 첫 검증을 전체 게임 완성으로 표기하지 않는다.

## 작업 순서

| 순서 | 내용 | 완료 확인 |
| --- | --- | --- |
| 1 | GDD 장면표·달력·4칸 규칙의 충돌 정리 | 시작 날짜, 첫 만남, 방송 날짜의 단일 기준 |
| 2 | 다인물 상태와 1인칭 기본 화면 | 만남 전/후, 실제 대면자 구분 |
| 3 | 개강 공통과 첫 만남 | 대표 세 만남과 선택 반응 |
| 4 | 나의 작곡과 사연/대표 방송 | 결과를 저장하고 후속 조건에 사용 |
| 5 | 교차 장면·메시지·선물·개별 대화 | 위치·목격·관계가 일치 |
| 6 | 연간 사건·라디오·고백·엔딩 | 각 루트와 예외 경로 도달 가능 |
| 7 | 개인 활동·부탁·수집 확대 | 중복 보상과 정보 누출 없음 |
| 8 | 정식 아트·음성·출시 검증 | 실제 제공 자산·접근성·플레이 평가 |

각 단계에서 저장·복원과 테스트를 함께 구현한다. 코드의 구조를 유지할지 전환할지는 개발 설계에서 정하며, 특정 엔진이나 이미지 제작을 이 문서가 강제하지 않는다.

## 필요한 상태의 논리적 구분

| 묶음 | 내용 | 검증할 것 |
| --- | --- | --- |
| 세계 시간 | 날짜·아침/오후/노을/밤·활동 | 비용은 한 칸에 한 번, 자동 수업·공휴일 분리 |
| 인물별 관계 | 만남·마음·관계 단계·사건 | 서로 다른 인물 ID와 반복 상한 |
| 익명 관계 | 발송·읽힌 사연·익명 마음 | 현실 마음과 섞이지 않음 |
| 정보 | 방송 청취·직접 들음·추측·정체 확인 | 누가 무엇을 언제 아는가 |
| 실제 등장 | 장소·칸·장면 참여자 | 지도 아이콘과 화면 입상 일치 |
| 교차 | 실제 목격자·질투·대답 보류 | 사건 발생 조건과 횟수 제한 |
| 활동 | 시작 여부·선택·결과·지급 | 저장·재개와 중복 차감 방지 |
| 수집 | 소유·공유·해금·회상 | 일시 일지와 영구 기록 분리 |
| 저장 경로 | 기존 저장 / 새 GDD 시작 | 기존 기록을 새 인물의 과거로 임의 변환하지 않음 |

위는 개념 계약이며 실제 필드명이나 확정 저장 버전이 아니다. 먼저 기존 저장을 읽고 보존하는 정책을 정한다. 예전 저장에서 세 인물을 만난 것으로 조작하거나, 기존 이벤트 ID를 새 인물 대본에 재사용하지 않는다. 안내 건너뛰기는 만남 완료와 구분한다.

## 필요한 검증 시나리오

| ID | 시나리오 | 통과 조건 |
| --- | --- | --- |
| T01 | 새 게임·도입 | 플레이어의 방과 일정이 먼저, 만나지 않은 인물의 사적 정보 비노출 |
| T02 | 입학식과 첫 인사 | 무대에서 봄과 이름·대화의 만남 이력이 정확히 구분 |
| T03 | 나리 첫 주 경로별 및 박람회 대체 | 최초 만남 한 번, 해당 카드와 후속 대사 일치 |
| T04 | 3/5 새터·첫 출근 | 다은과 서진 각각 해금, 첫 출근 급여 한 번 |
| T05 | 네 칸 활동·두 칸 외출 | 시간·기력·돈을 정확히 한 번 반영 |
| T06 | 3/2 지난 방송과 4/2 첫 방송 | 서로 다른 회차·지식·단서로 기록 |
| T07 | 방송을 듣지 않거나 다시 듣기 | 실제 경험에 따른 차이와 접근 조건 일치 |
| T08 | 사연 작성 후 취소/전송 | 전송하지 않은 초안은 방송 분기에 쓰이지 않음 |
| T09 | 멜로디 공유/비공유 | 인물의 직접 청취 이력과 후속 반응 일치 |
| T10 | 한 장소 두 인물/한 인물 | 실제 위치에 따른 교차·목격 판정만 발생 |
| T11 | 사건 진행 중 저장·재개 | 선택·날짜·비용 복원, 완료 보상 중복 없음 |
| T12 | 더블 클릭·오래된 버튼 | 같은 활동·선택 한 번만 처리 |
| T13 | 우정·연인·보류·다중 관계 | 각 관계와 고백 순서에 맞는 대사·결말 |
| T14 | 지나간 사건과 대체 만남 | GDD 조건에 따라 대체/놓친 기록, 근거 없는 강제 잠금 없음 |
| T15 | 이전 저장·손상 저장 | 기존 진행 보호, 새 사건 위조 금지, 잘못된 파일 거부 |
| T16 | 회상·도움·키보드·큰 글자 | 재정산 없음, 초점·자막·버튼 접근 가능 |
| T17 | 게임 내 날짜 진행과 미접속 | 감정 변화는 게임 내 GDD 규칙만, 현실 시간과 혼동 없음 |
| T18 | 방송 비밀과 다인물 지식 | 스포일러와 인물의 선행 지식 누출 없음 |

코드가 구현되면 기존 회귀 테스트와 새 상태 테스트, 실제 브라우저 플레이·화면·콘솔 확인을 수행한다. 이번 문서 작업에서 게임 테스트를 실행하거나 통과했다고 주장하지 않는다.
