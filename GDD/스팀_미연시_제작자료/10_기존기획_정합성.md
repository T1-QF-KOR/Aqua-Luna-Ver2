# 현재 GDD와 이전 실행본의 정합성

[목차](README.md) · 소스 및 GDD 열람 기준 2026-10-27 · 실제 실행 검증 아님

## 기준과 상태

사용자가 새 GDD의 한나리·오다은·백서진과 라디오 구조를 사용하고 이전 단일 인물 중심 기획은 사용하지 않겠다고 명확히 했다. 이 자료는 그 기준에 맞춘다. 새 GDD의 본문은 초안·검토 대기이며 게임 코드로의 반영을 의미하지 않는다. 이전 실행본은 현재 코드·기존 저장을 보존하고 전환을 계획하는 목적에서만 언급한다.

## 반드시 구분할 항목

| 항목 | 새 GDD | 이전 실행본에서 확인한 기반 | 제작 시 처리 |
| --- | --- | --- | --- |
| 서사 주인공 | 이름을 정하는 남자 신입생, 1인칭 | 특정 상대가 자주 표시되는 일상 화면 | 내 방·개인 일상부터 시작하고 실제 대면자만 표시 |
| 인물 | 나리·다은·서진 | 단일 관계 구조 | 인물별 마음·만남·장면·일정 분리 |
| 시간 | 하루 4칸, 평일 수업, 오후/노을 선택, 밤 | 자유 시간 3칸 기반 | 비용·시간·세이브 규칙을 새 경로 기준으로 전환 |
| 날짜 | 2026/3/2 방 입주, 3/3 입학식 | 2026 달력과 대학 경로에 따른 시작일 | 기준일을 유지할지 명시하고 GDD 사건 날짜 검증 |
| 플레이어 음악 | 작곡 전공 가안·내 멜로디 | 이전 보컬 중심 경험 | 설정 확정 전 대사·능력에 가안 표시 |
| 방송 | 시즌별 익명 방송·사연·단서 | 기존 메시지/스토리 기능 | 별개의 방송 청취·정보·정체 상태 필요 |
| 교차 | 같은 장소의 여러 인물·목격·질투·소문 | 한 인물 중심 장면 | 참여자 위치·지식·횟수 조건 검증 |
| 기억 | 인물별 기억 카드와 라디오 정보 | 앨범·기록·코스 체험 | 데이터 중복을 피하고 새 사건과 별도로 연결 |
| 결말 | GDD 가안 12종 | 이전 저장의 관계·결말 | 새 판정은 별도. 과거 기록을 새 인물 결말로 임의 변환 금지 |
| 에셋 | 세 인물·방송국·자취방 등 새 자료 필요 | 기존 캐릭터·배경 | 인물 그림을 다른 인물로 이름만 바꿔 재사용하지 않음 |

정확한 4칸 시간표, 능력치, 발송과 고백의 조건은 이 참고 폴더가 아니라 현행 GDD의 각 항목을 따른다. 상점 소개에서 확인한 원작의 장점이 지금 게임의 규칙을 자동 확정하지 않는다.

| 경제·관계 수치 | 각 GDD 수치가 가안 | 1년 도달 가능성, 반복 피로, 특정 선택의 강제성 플레이 검증 |
| 기존 기능 | 이전 코스·의상·체험은 새 GDD에서 별도 결정 | 에셋 재사용의 적합성, 데이터·저장 호환, 권리 |
| 분량·아트 | 목표와 초안 수량 | 실측 완료가 아니며 정식 그림·노래·음성은 제작 필요 |

## 이전 저장과 기록을 다루는 원칙

이전 플레이 기록은 사용자의 데이터다. 새로운 게임을 시작할 때 이전 저장에 없는 세 사람의 만남이나 선택을 만들어 넣지 않는다. 새 사건 ID를 옛 사건의 다른 뜻으로 재사용하지 않는다. 향후 가져오기·이전 실행 여부는 데이터 형식을 확인한 뒤 결정하며, 변환이 불가능하면 사실을 설명하고 원본을 보존한다.

기존 코스를 활용할 경우 장소 배경·일반 퍼즐 규칙과 특정 인물의 대사·의상·상태를 분리해 확인한다. 새 인물의 허구 설정과 기존 대사를 자동 혼합하지 않는다. 이전 인물 이름을 새 인물 이름으로 일괄 바꾸는 것은 새 이야기 제작이 아니다.

## 참조와 문서 관리

- 새 기획 전체: [GDD 목차](../README.md), [인물](../02_세계관_인물.md), [생활](../04_생활_시간.md), [라디오](../07_라디오_아쿠아루나.md), [교차](../08_하렘_교차_질투.md).
- 기존 자료는 `archive/`의 보관 기획과 현재 `src/`를 읽어 구분한다. 보관된 기획을 새 방향의 결정으로 해석하지 않는다.
- 실제 제작 시 결정한 사항·영향받은 사건 ID·기존 저장 대책·에셋 출처·검사 결과를 관련 문서에 함께 기록한다.
- Game Studio의 플레이어 행동·시간·UI·플레이 검증 관점을 이 문서 묶음에 반영했다. Game Development Studio의 전용 `game-dev` CLI는 이전 확인 시 없었고 이 문서 작업에서 설치·에셋 생성·GPU 캡처를 실행하지 않았다.
