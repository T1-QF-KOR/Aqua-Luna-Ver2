# 학교의 이야기와 수업 뒤의 선택

2026-10-30 · [기존 조사 목차](README.md) · 이번에는 실제 코드에 연결한 범위

사용자는 등교일에 학교에서 메인 이야기를 본 뒤 장소를 선택하고, 그곳에서 다른 사건을 겪는 흐름을 원했다. 이 구조는 신입생의 생활과 관계를 함께 다루는 Aqua Luna에 어울린다고 판단했다. 학교는 공통의 연속 이야기, 오후는 플레이어가 생활과 관계의 방향을 정하는 시간으로 구성했다. 아래의 적용 방식은 우리 게임의 설계 판단이다. 참고작의 내부 진행 순서를 그대로 재현했다는 뜻은 아니다.

## 실제로 바뀐 하루

1. **등교일 아침:** 날짜에 맞는 학교 이야기를 본다. 1학기는 네 마디 자기소개부터 학기말 발표로, 2학기는 학교의 소리를 담는 과제부터 첫해의 마지막 제출로 이어진다. 32주, 요일별 160개 중심 문장을 작성했고 실제 학사 달력의 등교일 151일을 검사했다. 입학식·개강·특별 녹음 등 기존의 지정 아침 장면은 우선한다.
2. **수업이 끝나면:** 같은 날짜 오후에 오른쪽 전체 장소 패널이 열린다. 장소를 누르는 것은 미리 보기이고 방문과 시간 보내기는 따로 확정한다. 수업의 기력 −5와 학습 처리는 저장된 줄 효과로 한 번만 반영한다.
3. **장소에서:** 기존 관계 사건·약속·만남을 우선한다. 일반 활동 뒤에는 장소별 일상 사건이 나올 수 있다. 그런 사건이 없는 등교일에는 첫 자유 활동 뒤에 장소와 수업을 잇는 짧은 이야기가 나온다. 기록을 남기거나 그냥 일어나는 선택이 가능하다. 새로운 인물 출현이나 곡 녹음을 만들어 내지는 않는다.
4. **다음 수업:** 실제로 남긴 장소 기록과 과제 방향만 대사로 돌아온다. 방문을 취소하거나 기록하지 않은 선택은 기록으로 취급하지 않는다.

주말·공휴일·방학에는 일반 학교 장면을 재생하지 않는다. 학교 이야기의 등장자는 같은 시간대의 저장된 출석 계획에 실제로 있는, 이미 만난 인물만 사용한다. 나리는 학년이 섞이는 화·목 공통 수업에만 합류하며 휴학생 서진을 강의실에 넣지 않는다. 지도는 만난 인물의 현재 위치도 미리 표시하지 않는다.

## 히로인 그림과 겨울 장면

- 나리: 라벤더 니트와 아이보리 코트, 성탄 방송 뒤 강변 벤치의 「대본을 접은 밤」.
- 서진: 남색 코트와 회색 목도리, 손바닥에 눈을 받는 「손바닥 위의 첫눈」.
- 다은: 기존 니트 베스트 위에 주황색 더플코트, 휴대폰을 내려 두고 말하는 「숫자보다 먼저 본 얼굴」.

세 CG는 기존 캐릭터 그림을 참조해 built-in image_gen으로 새로 제작했다. 실제 해당 장면에서 본 뒤에만 휴대폰 앨범에 나타나며, 필터와 큰 그림 감상이 가능하다. 나리의 옷 두 벌은 사용자가 좋아한 실루엣을 그대로 두고 색만 수정한 버전을 계속 사용한다. ## 확인 범위와 다음 검토

학교·장소 연결, 저장 복원, 실제 출석, 만남 미리 보기의 비공개, 성탄 분기, 실제 게임 처리로 308일 진행을 검사한다. 나리의 성탄 CG와 감상 버튼은 Safari에서 실제 확인했다. 감상 창의 잘림을 발견해 레이아웃을 수정했으나, 최종 레이아웃과 새 학교 장면의 브라우저 재검증 때 Safari 연결이 `cgWindowNotFound`로 끊겼다. 자동 규칙 검사와 화면 검증을 구별한다.

현재 플레이 가능한 구간은 2027년 1월 3일까지다. 겨울 후반과 최종 결말, 장기간의 실제 읽기 속도·반복 피로도, 고백 능력치 조건의 체감 균형, 더 많은 표정 차분과 음성은 아직 검토·제작 대상이다. 날짜별 글이 있다는 사실만으로 한 해 전체가 완성되었다고 판단하지 않는다.
