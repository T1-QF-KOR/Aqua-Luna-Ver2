# 화면과 연출 제안

[목차](README.md) · [화면 GDD](../10_화면_조작.md) · PC 전용, 현재 텍스트·DOM 기반

## 화면의 중심

인물의 입상이 기본 화면에 항상 머무는 대신 플레이어가 현재 있는 공간, 누구를 만나는지, 무엇을 할 수 있는지를 보여 준다. 이는 사용자의 요청에 따른 연출 방향이며, 조사한 모든 게임이 같은 표시 규칙을 가진다는 의미는 아니다.

| 장면 | 보이는 것 | 인물 표시 | 조작 |
| --- | --- | --- | --- |
| 3/2 자취방 | 상자·시간표·나의 독백 | 상대 없음. 민재 대화 시에만 표시 | 방 정리·고향 연락·지난 방송 |
| 캠퍼스 | 날짜·칸·장소·할 수 있는 일 | 아직 만나지 않은 사람은 지도에 표시하지 않음 | 장소 선택·방문 확정 |
| 대면 | 해당 장소·현재 등장한 인물 | 한 명 또는 같은 장소의 두 명 | 인사·대화·선물·함께 시간 |
| 교차 장면 | 두 사람 이상의 상호 대화 | 작가가 지정한 인물만 좌·우/중앙 | 누구에게 답할지 선택 |
| 개인 활동·일 | 작업 공간·도구·내 결과 | 실제 방문/공동 활동의 경우에만 상대 표시 | 작곡·근무·기록 |
| 라디오 | 내 방·방송 표시·자막 | GDD의 방송 화면 원칙을 따름. 정체 스포일러 없음 | 듣기·사연·다시 듣기 |
| 휴대폰 | 연락·달력·기억·설정 | 연락처 교환/만남 이후 해당 인물 | 답장·확인·보류 |
| 회상 | 그때의 장소와 등장자 | 과거 기록에 실제 있던 사람 | 읽기 전용 |

## 정보 계층

가장 먼저 오늘의 날짜·칸·장소, 다음으로 남은 기력·소지금, 그다음으로 현재 행동과 열린 사건을 보여 준다. 장기 관계·취향·수집은 휴대폰/기록에서 확인한다. 인물 마음의 숫자는 GDD의 기본 숨김·설정 공개 가안을 따른다.

이벤트 아이콘은 플레이어가 실제로 알 수 있는 곳에만 붙인다. 방송국 관련 작가용 위치나 비밀의 정답을 지도에 노출하지 않는다. 두 인물이 화면에 있을 때 다른 사람을 고르면 누가 보고 있는지와 그 인물이 실제로 그 자리에 있는지 일치시킨다.

## 새 게임과 혼자 있는 화면

새 게임의 첫 문장은 주인공이 서울의 방에 들어온 상황과 오늘의 목적을 전달한다. 내 방에서 다른 사람이 대면하는 듯한 캐릭터 그림·대사·상태창을 항상 띄우지 않는다. 장소에 따라 내 생각, 할 일, 새 메시지처럼 이유가 있는 문장으로 안내한다.

카페에서 일할 때는 플레이어가 근무 중이라는 화면을 보여 준다. 서진이 교육하거나 방문객이 오는 순간은 대면 장면으로 따로 처리한다. 기존 SD 연출을 그대로 주인공의 얼굴처럼 사용하지 않는다.

## 방송과 선택 연출

지난 시즌 듣기와 새 시즌 방송은 제목·날짜를 구분한다. 스포일러 방지를 위해 방송 중 UI는 DJ 별명과 공개된 말만 표시한다. 어떤 사건으로 정체를 알았는지에 따라 이후 표현이 달라지더라도 다른 인물에게 그 지식이 전파된 것처럼 표시하지 않는다.

사연 초안은 수정 전·수정 후·보내기 확인을 구분한다. 실제 전송된 기록만 방송 분기에 사용한다. 방송 음성이 없더라도 같은 내용을 자막으로 알 수 있다.

## 아트·음향·접근성

기존 배경과 아트는 실제 장면의 인물·장소·시간대에 맞을 때만 재사용한다. 세 인물의 정식 그림, 다인물 배치, 자취방·방송국·학교 배경, 방송 신호음·자막은 별도 자산 목록으로 분리한다. 문서화는 에셋 제작 완료를 의미하지 않는다.

최소 1280×720 PC 화면에서 인물·대사·선택이 겹치지 않는지 본다. 마우스와 키보드로 동일한 선택을 할 수 있게 하고, 화면 확대·움직임 줄이기·대사 자동 재생 설정에서도 초점과 텍스트가 사라지지 않게 한다. Esc로 닫은 활동은 명시적 포기와 구별한다.
