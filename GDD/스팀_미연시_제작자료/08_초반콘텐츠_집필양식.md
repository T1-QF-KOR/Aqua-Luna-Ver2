## 첫 주부터 첫 방송까지

아래는 실제 GDD의 사건 흐름을 읽고 제작 작업을 분리한 예시다. 개인 활동과 부탁은 선택형 제안이며 기존 대본 전체를 대체하지 않는다. 날짜가 적힌 사건의 실제 조건은 장면표를 우선한다.

| 날짜 | 공통/첫 만남 | 개인 생활·제안 활동 | 남는 기억 |
| --- | --- | --- | --- |
| 3/2 월 | 자취방, 민재, 고향 메시지 | 지난 시즌 다시 듣기 선택 | 실제로 지난 방송을 들었는지 |
| 3/3 화 | 입학식 무대와 무대 뒤, 첫 주 분기 시작 | 강의실·옥상·강변 선택 | 나리와의 해당 첫 교류 카드 |
| 3/4 수 | 수업과 자유 장소 | 작곡·캠퍼스 탐색 후보 | 내 멜로디, 단 아직 공유 전 |
| 3/5 목 | 새내기 배움터에서 다은 | 공강·동기 대화 | 첫 인사, 과 단톡방 |
| 3/6~9 | 각자의 수업·생활 | 개인 연습·휴식 | 멜로디·장소 경험 |
| 3/10 화 | 동아리 박람회, 다은 드러머 오디션, 나리 대체 첫 만남 | 밴드·방송국·안 함 선택 | 동아리·인물별 첫 만남 |
| 3/11 이후 | 수·금·토 첫 출근에서 서진 | 카페 근무, 선택적 주문 체험 | 교육·첫 급여·대화 |
| 4/2 목 | 첫 정규 방송 | 주차 조건을 충족한 사연·청취 | 방송 청취와 단서. 정체는 별도 조건 |

첫 주 나리의 세 경로는 독립된 세 명의 첫 만남이 아니라 **하나의 첫 만남 변형**이다. 입학식 무대 뒤에서 물을 건네 이미 나리를 만난 경우에는 세 경로가 열리지 않는다. 그렇지 않을 때 처음 간 장소 또는 뒤늦은 박람회 대체를 적용하며 중복 재생하지 않는다. 입학식에서 무대를 보았다는 사실과 개인적으로 인사를 나눈 사실도 구분한다.

## 첫 세 만남의 장점과 작성 지침

| 인물 | 시작 맥락 | 플레이어의 질문 | 좋은 후속 회수 |
| --- | --- | --- | --- |
| 나리 | 무대 밖에서 말하기 어려운 선배 | ‘이 사람에게 언제 말을 걸고 기다릴까’ | 내 멜로디·멘트 수첩·강변 대화 중 실제 본 것 |
| 다은 | 먼저 인사하는 새터 동기 | ‘장난에 어떻게 답하고 언제 진지하게 들을까’ | 첫 단톡방·드럼 오디션 |
| 서진 | 근무를 가르쳐 주는 선배 | ‘일을 배우며 상대의 시간을 존중할까’ | 교육 중 선택, 마감 플레이리스트 |

각 장면에 주인공의 일정과 상대의 목적을 함께 쓴다. 한 인물의 첫 장면을 완료했다고 다른 인물의 연락처와 취향을 자동 해금하지 않는다.

## 새 사건 작성 양식

| 필드 | 기입할 내용 |
| --- | --- |
| ID·상태 | 기존 장면표 ID 또는 충돌 없는 새 ID, 초안/검토/구현 |
| 시점·장소·등장 | 게임 날짜·칸·등장자·대면/방송/메시지 구분 |
| 플레이어 목적 | 그 장소에 온 이유, 혼자 하려던 일 |
| 인물 목적 | 각자의 그날 일정과 원하는 것 |
| 조건 | 선행 사건·날짜·능력·관계, AND/OR 명시 |
| 못 본 경우 | 다음 기회, 박람회 대체 또는 결말 카드에 남길 정보 |
| 본문 | 플레이어의 관찰·말·속마음, 상대 발화 구분 |
| 선택·반응 | 내 선택, 실제 응답, 다른 인물의 목격 여부 |
| 결과 | 시간·기력·돈·관계·기록의 지급 시점과 중복 방지 |
| 지식 경계 | 누가 방송에서 들었고 직접 들었는지 |
| 회수 위치 | 어떤 후속 장면·방송·카드에 돌아오는지 |
| 에셋·접근성 | 기존/추가 그림, 음성 부재 시 자막, 키보드 |
| 저장·QA | 선택 중 저장, 복원, 회상에서 재정산 방지 |

## 창작 예시 · 강의실의 악보

현행 대본의 분위기를 검토하기 위한 **신규 예시**다. 원작 대사나 확정 대본이 아니다. 플레이어가 합동 수업 뒤 악보를 줍는 상황에서 나리와 처음 제대로 이야기한다.

> 나의 생각: 내가 적은 악보는 멜로디만 있고 가사가 비어 있다. 보여 주기엔 조금 빠른가.
> 나리: …가사는?
> 나: 아직 못 썼어요.

| 선택 | 나의 태도 | 상대의 응답 예시 | 기록·후속 |
| --- | --- | --- | --- |
| 내가 고른 이유 말하기 | ‘멜로디부터 적었어요. 말은 조금 더 찾아보려고요.’ | 나리: ‘…나도, 첫 줄이 어려워.’ | 멜로디를 보여 준 사실. 실제로 들려줬는지는 별도 |
| 먼저 물어보기 | ‘선배는 가사를 먼저 써요?’ | 나리: ‘나는… 남이 쓴 걸 더 많이 불러.’ | 직접 들은 대답. 감춰진 방송 정체는 알지 못함 |
| 시간을 둔다 | 악보를 정리하고 ‘다음에 들려드릴게요.’ | 나리: ‘응. 나중에.’ | 공유 제안만 기록. 들었다는 플래그는 생기지 않음 |

이 표는 신규 집필 예시이며 기존 대본의 선택지를 대체하지 않는다. 현행 `n-meet-class` 대본에서는 나머지 여섯 마디를 이어 부르는 첫 번째 선택에만 「나리가 내 멜로디를 들음」이 기록된다. `n-demo` 등 기존에 직접 듣는 다른 사건의 기록도 유지한다. 방송 18회 단서에 쓰이는 플래그를 개인 활동 완료만으로 새로 켜지 않는다.

## 창작 예시 · 카페 주문 확인

서진이 초보자에게 주문표를 보여 준다. 플레이어는 커피와 옵션 카드를 고르고 최종 확인한다. 잘못 골랐다면 서진이 고쳐야 할 부분을 짚고 다시 선택한다. 근무는 현행 시간·급여로 한 번 정산한다. 이 활동의 점수로 개인사를 즉시 알아내지 않는다.

## 라디오 주차 검증 양식

회차·날짜·방송을 들었는지·사연을 보냈는지·주제·방송이 실제로 읽은 것·플레이어가 직접 아는 정보·추측 가능한 단서·인물별 정보 상태·방송 뒤 후속 대사를 한 표에 적는다. 시간 순서상 나오지 않은 사연이나 누가 썼는지 모르는 정체를 미리 노출하지 않는다.

## 대사 검토 질문

이 말은 누가 직접 들었는가? 처음 만난 사람에게 이미 친한 호칭을 쓰지 않는가? 세 사람이 서로에게도 말하는가? 한 사람을 택한 뒤 다른 사람의 반응이 현재 위치와 관계에 맞는가? 방송 정보와 개인의 사생활을 구분하는가? 개인 활동이 이후 한 장면에서라도 언급되는가? 선택을 미루거나 낮은 점수를 받았을 때도 적절한 후속 상황이 있는가?
