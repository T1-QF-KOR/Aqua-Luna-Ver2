# 스팀 미연시 조사와 제작 참고자료

작성일 2026-10-27 · 기준: 새 Aqua Luna GDD · 상태: **조사에 기반한 제안 / 게임 코드 미반영**

플레이어가 자취를 시작한 신입생으로 1년을 보내며 한나리·오다은·백서진을 만나고, 캠퍼스의 현실 관계와 익명 라디오 「아쿠아 루나」를 함께 경험하는 게임을 위한 자료다. Steam 공개 소개에서 확인한 여덟 작품의 특징을 분석하고, 지금 만들 게임에 어울리는 장점을 선별했다.

현재 [GDD 게임 개요](../01_게임_개요.md)와 [콘텐츠·로드맵](../12_범위_로드맵_코드반영.md)은 초안·검토 대기다. 본 폴더도 제작을 돕는 참고·제안이며 새 수치나 기능을 확정하거나 구현한 결과가 아니다. 사용자가 지정한 대로 이전 단일 인물 중심 기획은 새 콘텐츠에 사용하지 않는다. 이전 저장·코드를 다룰 때만 기존 실행본으로 구분한다.

## 문서의 상태 표시

- **확인:** 스팀 공식 소개 또는 저장소에서 직접 읽은 내용이다. 실제 게임을 플레이했다는 뜻은 아니다.
- **장점 해석:** 확인한 기능이 어떤 경험을 만들 수 있는지 분석한 것이다. 작품 전체의 품질 판정은 아니다.
- **Aqua Luna 적용 제안:** 위 장점을 새로 해석한 창작안이다. 참고작에 동일한 기능이 있다고 주장하지 않는다.
- **P0 / P1 / P2:** 작은 첫 검증, 검증 후 확장, 규모 검토 후 확장. 내용·수량·일정은 제안이다.

기본 방향과 수치는 [현재 GDD](../README.md)를 우선 읽는다. 특히 하루 4칸, 방송 일정, 인물별 위치·관계와 엔딩은 [04](../04_생활_시간.md), [03](../03_관계_고백_엔딩.md), [07](../07_라디오_아쿠아루나.md), [08](../08_하렘_교차_질투.md)을 따른다. 06 문서의 새 활동은 이 규칙 위에 얹을지 검토하는 후보이며 기존 GDD의 판정식을 암묵적으로 바꾸지 않는다.

## 제작에서 놓치지 않을 것

1. 처음부터 상대의 그림을 항상 띄우기보다 내 방·수업·일·작곡에서 출발한다.
2. 서로 다른 방식으로 세 사람을 알아간다. 첫 만남, 연락, 대면, 현재 위치는 각각 다른 정보다.
3. 한 칸에 누구를 만날지 고르는 긴장은 살리되 일정과 놓친 기회의 이유를 이해할 수 있게 한다.
4. 라디오에서 **들은 것**, 직접 **알게 된 것**, 개인적으로 **추측한 것**을 구별한다. 정체는 시청자용 설명과 플레이어의 지식이 다르다.
5. 나만의 활동 결과가 대화·부탁·기억에 사용된다. 같은 행동을 반복해 보상을 무제한 얻지 않는다.
6. 관계의 결과와 각 인물의 진로는 구분하고, 인물들의 선택권과 서로 간 관계를 대사로 표현한다.
7. 한 해 분량을 만들기 전에 첫 만남과 대표 방송 한 회가 성립하는지 작게 검증한다.
