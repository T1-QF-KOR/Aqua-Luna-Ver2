## 읽는 법

이 대본은 승인 즉시 `src/story.js`로 옮길 수 있도록 게임의 장면 형식을 그대로 따릅니다.

| 표기 | 뜻 |
| --- | --- |
| `(서술)` | 화면 서술. 2인칭 '당신'은 서술에서만 씁니다 |
| `수련 〔smile〕` | 수련의 대사와 그 줄의 표정. 표정 7종: neutral · smile · thoughtful · shy · surprised · worried · playful |
| `나` | 플레이어가 소리 내어 하는 말 |
| `(속)` | 플레이어의 속마음 |
| `하윤` · `윤서` · `교수` | 그림 없는 조연. 이름표만 표시 |
| `수련 · 메시지` | 휴대폰 메시지 연출 |
| `{bg · cam · sfx}` | 연출. 카메라: wide · lean · close · back · away · blur · shake · black / 효과음: phone · page · wind · bell · chord · heart · trust |
| `[CG01]` | 이벤트 CG가 표시되는 줄 |
| `▶ ①` | 선택지. 따옴표 안이 선택 버튼 문구 |
| `→` | 선택 효과. 호감·신뢰·기분 수치와 기록 |
| `★` | 이후 장면이나 결말을 바꾸는 선택 |
| `◆ [능력치 N]` | 능력치가 있어야 열리는 특별 선택지 |
| `〈조건〉` | 기록이나 수치에 따라 그 줄만 바뀌는 부분 |
| `↳ 반말` | 8장에서 말을 놓은 경우의 대사 |

수치는 모두 가안입니다. 선택 효과는 장면이 끝날 때 기존 성장 곡선을 거쳐 반영됩니다.
