# 조건부 회상과 추가 문구

[시나리오 목차](README.md) · 기준일 2026-10-07 · 근거: [app.js](../../src/app.js)

정적 장면 외에 대화 첫 장면에서 아래 문구를 덧붙인다. 이 문서는 진행 중 대화 화면의 회상 조건을 정리하며, 저장에 없는 선택을 새로 생성하지 않는다.

| 조건 | 추가 문구 |
| --- | --- |
| 선택 기록이 있는 최근 데이트 첫 선택이 `quiet` | “지난번엔 조용히 쉬는 시간을 함께했죠. 오늘도 편하게 있어요.” |
| 위 첫 선택이 그 외 | “지난번엔 서로의 하루를 이야기했죠. 오늘은 어떤 하루였는지 궁금해요.” |
| 그 데이트와 현재 출발 코디·스타킹이 같음 | “{당시 일수}일째에 같이 나갔던 차림이네요. 그날의 길이 생각나요.” |
| 산책 약속이 있고 기본 산책에 출발 | “다음엔 강가에서 만나자고 했죠. 오늘 그 약속을 지키네요.” |
| 산책 약속이 있고 다른 장소에 출발 | “다음 산책 약속은 기억하고 있어요. 오늘은 이곳에서 쉬어요.” |
| 연인 관계의 데이트 | “연인이라고 모든 걸 알게 되는 건 아니네요. 오늘의 당신도 새로 알고 싶어요.” |
| 친구로 관계를 정한 뒤 데이트 | “친구라고 말하고 나니 편해졌어요. 오늘도 솔직하게 이야기해요.” |
| 세션: 예전 곡 선택 | 접힌 악보가 펼쳐져 있습니다. 수련은 예전 곡을 지금의 호흡으로 부르기로 했습니다. |
| 세션: 다른 곡 선택 | 처음 보는 악보가 놓여 있습니다. 수련은 과거의 곡 대신 오늘 고른 노래를 준비했습니다. |
| 연인 후일담 | 손이 스치자 수련이 먼저 손을 내밉니다. “친구로 걷던 길을 연인으로 걸으니 조금 다르네요.” |
| 친구 후일담 | 수련이 옆자리를 비워 둡니다. “오래된 친구에게도 처음 하는 이야기가 남아 있네요.” |
| 테마 후속 사건 | 해당 테마에서 방문한 코스를 콘텐츠 배열 순서로 찾은 마지막 항목의 첫 방문 날짜·장소·두 번째 선택·응답을 표시 |

테마 후속 사건의 회상 코스는 최근 방문 날짜 순으로 선택하지 않는다. 현재 코드의 배열 순서에 따른 동작이며, 추후 회상 기준을 변경하면 이 명세도 수정한다. 장면이 넘어가면 직전 선택과 응답을 본문 위에 표시하고, 마지막 선택의 응답은 결과 화면에서 표시한다.
