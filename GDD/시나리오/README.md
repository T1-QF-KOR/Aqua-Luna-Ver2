# 시나리오 전체 목차

[전체 GDD](../README.md) · 설정 개정 2026-10-22

수련은 **실용음악과 보컬 전공**이며, 좋아하는 장르와 주로 부르는 장르는 모두 **발라드**다. 실행본과 아래 대학편 초안의 음악 설정은 [보컬·발라드 개편 기록](../../docs/BALLAD_SETTING_2026-10-22.md)을 따른다.

## 대학 시절 개편 초안 · 2026-10-11

- [대학 시절 메인 시나리오](10_대학시절_메인_시나리오.md): 같은 전공·같은 학년에서 친해진 수련과 플레이어의 한 학기. 프롤로그·7개 장·에필로그, 총 18장면의 대사·선택·응답과 관계 분기. 게임 코드 미반영.
- [전체 스토리라인과 설정 구분](../17_대학시절_스토리라인.md): 사용자 확정 사항, 집필 가안, 대학 생활과 버츄얼 활동의 연결, 기존 콘텐츠 개편 방향.

## 현재 실행본 대본 · 대학편 개편 전

대학 배경을 소개하는 [새 게임 인트로 5장면](11_새게임_인트로.md)은 실행본에 추가했다. 아래 주요 사건·데이트 대본은 기존 구성이다. 대학편 메인 18장면 전체를 구현했다는 뜻은 아니다.

현재 실행본의 전체 정적 대본을 코드에서 추출했다. 51개 데이트와 35개 이야기, 총 360개 선택 장면을 포함한다. 공통 장면도 실제 코스 구성대로 반복 표기한다. 분기별 응답을 모두 싣기 때문에 한 번의 플레이에서 전부 읽는 분량이 아니다.

대본을 수정할 때는 해당 콘텐츠 ID의 코드와 이 문서를 함께 갱신한다. 이 폴더 자체를 게임이 읽어 실행하는 구조는 아니다. 사건 조건 변경은 스토리 시스템, 코스 비용 변경은 경제·데이트 문서에도 반영한다.

신규 대학 시절 초안은 검토용 원고이므로 기존 실행본 대본과 구분해 보관한다. 실제 구현 시 관련 코드·조건·콘텐츠 집계를 함께 갱신한다.
