# 09. 화면·조작·시청각

[전체 GDD 목차](README.md) · 기준일 2026-10-07 · v0.1

## 주요 화면 — 구현

| 화면 | 주요 역할 |
| --- | --- |
| 타이틀 / 일상 | 새 게임·이어하기, 날짜·자원 확인, 일·휴식·다음 날 |
| 관계와 이야기 | 현재 관계, 열린 사건, 다음 개방 단서, 지난 이야기 |
| 외출 준비 / 대화 | 장소·코디·예산 확인, 선택지와 수련의 응답 |
| 상점 / 옷장 | 구매·보유·착용, 상품 그림 미리보기 |
| 탐방 수첩 / 체험 | 방문 진행도, 첫 추억, 퍼즐 시작·재개 |
| 앨범 / 갤러리 | 과거 데이트, 시간·코디·표정 조합 감상 |
| 저장 / 설정 | 자동·수동 저장, 파일 백업, 읽기·그림·움직임·소리 설정 |

마우스·Tab/Enter로 주요 버튼을 조작하고 Esc로 열린 창을 닫는다. 탐색 체험은 방향키/WASD와 화면 버튼을 지원한다. 읽기 크기는 15 / 18 / 21px, 보조 그림 끄기와 움직임 줄이기를 제공한다.


아트와 사운드 상세는 [아트·사운드 명세](10_아트_사운드.md)를 참고한다.

## PC 화면 배치

관리 UI(날짜·소지금·시간·기력·활동·저축·관계·다음 날)는 왼쪽 55% 너비에 모은다. 오른쪽 34% 너비는 수련 전용으로 두고 관리 패널을 겹치지 않는다. 낮은 창에서는 세로 스크롤을 허용한다. 전신과 허벅지까지 그려진 원본의 머리 크기를 맞추기 위해 표시 높이를 구분하고, 잘린 원본 하단은 자연스럽게 흐린다. 옷장·상점 미리보기에는 머리 위와 발 아래 여백을 남긴다.

## 화면 이동과 피드백

- 타이틀 → 새 게임 또는 이어하기 → 일상 화면.
- 일상 화면 → 일하기 / 외출 / 옷장 / 상점 / 관계 / 기록 / 저장 모달.
- 관계 화면 → 열린 이야기 또는 진행 중 이야기 재개. 탐방 수첩에서 코스와 체험에 접근.
- 외출 준비 → 자원 비교 → 출발 → 대화 → 결과 → 일상 화면.
- 체험 → 닫아 보존하거나 명시적으로 중단 → 진행 중 대화 또는 수첩으로 복귀.

현재 소지금·남은 시간·기력·호감·신뢰를 확인할 수 있어야 한다. 행동 불가 버튼에는 부족한 조건을 표시한다. 출발 전 미리보기와 취소는 상태를 바꾸지 않는다. 완료와 실패 알림은 열린 모달에서도 읽을 수 있게 표시한다.

모달 제목, 버튼 접근성 이름, 알림 영역, 키보드 포커스를 사용한다. 대화의 다음 장면에서는 본문으로 읽기 위치를 옮긴다. 실제 스크린리더 사용성은 검증 완료로 간주하지 않는다. PC 전용으로 최소 1280 × 720, 권장 1440 × 900 이상을 기준으로 한다. 작은 창에서도 PC 배치를 유지하며 스크롤한다. 모바일 레이아웃과 터치 전용 최적화는 제공하지 않는다.
