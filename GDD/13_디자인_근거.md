# 13. 디자인 근거 — 왜 이렇게 만드나

> 규칙과 수치는 03~09장이 기준이다. 이 문서는 **이유**를 적는다.

## 1. 결론

연애 시뮬레이션 상위권 작품의 공통점은 시스템의 양이 아니라 **인물이 살아 있다는 느낌**, 그리고 **누군가를 고르면 누군가를 놓친다는 감각**이다. 한 사람만 있는 게임에는 두 번째가 없다. 그래서 이번 개편은 *세 사람이 서로를 아는 세계*를 만드는 데 집중했다.

## 2. 재미의 기둥과 가져온 곳

| 기둥 | 이 게임에서 | 참고 작품 |
|---|---|---|
| 새로운 사람을 만나는 설렘 | 개강 첫 주 장소별 첫 만남, 캠퍼스 지도 | 도키메키 메모리얼, 아마가미 |
| 한 사람을 읽는 재미 | 숫자 없는 마음 단계, 화제·선물 취향, 민재에게 묻기 | 아마가미, 스타듀 밸리, Lake |
| 내 1년을 짜는 재미 | 하루 4칸, 요일별 위치, 알바·공부·만남이 칸을 다툼 | 페르소나 시리즈 |
| **여러 사람 사이의 긴장** | 질투(자각 → 서운함), 목격, 소문, 성탄 초대, 발렌타인 | 도키메키 메모리얼(폭탄·하교 목격), 아마가미(라이벌 장면), 화이트 앨범 2(얽힌 관계) |

| 두 길로 다가가는 이야기 | 익명 라디오, 썼다 지우는 사연, 정체를 밝히는 타이밍 | Emily is Away, 미스틱 메신저 |

## 3. 하렘을 넣는 방식

### 스팀 공식 소개에서 확인한 추가 참고

| 게임과 확인한 구조 | 이 GDD에 반영한 판단 | 경계 |
|---|---|---|
| [러브 딜리버리](스팀_미연시_제작자료/01_스팀게임별_분석.md): 주인공의 일·자기 계발과 관계 | 자취·작곡·카페 근무를 나의 일상으로 둔다 | 구체적 초반 조작과 밸런스는 직접 검증하지 않음 |
| 썸썸 편의점: 일터와 관계 선택 | 카페·학교가 자연스러운 재회의 장소가 된다 | 특정 매칭 앱이나 일터 경영 기능을 복제하지 않음 |
| Love Esquire: 능력 성장과 관계 | 지식·체력·감수성에 서로 다른 활용을 부여한다 | 전투를 도입하거나 원작의 수치를 가져오지 않음 |
| Love on Leave: 탐색 결과를 부탁·선물에 사용 | 혼자 발견한 기록을 공유·대화로 연결한다 | 사진·게시판은 비용과 에셋이 미정인 후보 |
| Love Too Easily: 활동 단서의 후속 활용 | 활동·방송·기억의 결과와 나중 장면을 연결한다 | 반응속도 QTE나 원작의 추리 구조를 필수로 넣지 않음 |
| Dream Daddy: 사이드 퀘스트·데이트별 활동 | 조연의 부탁과 장소별 짧은 체험을 검토한다 | 새로운 대본·퀘스트 수량은 별도 집계 |

이는 공개 소개를 토대로 한 설계 해석이다. 실제 플레이로 초반 화면, 반복 피로도나 수치 효과를 검증했다는 뜻은 아니다. 세부 기능과 미확인 범위는 [스팀 조사](스팀_미연시_제작자료/01_스팀게임별_분석.md), 새 게임의 확정·후보 경계는 [14장](14_개인활동_선택형체험.md)에 둔다.

| 결정 | 이유 |
|---|---|
| 질투의 첫 번째는 **마음 +** | 도키메모식 폭탄은 벌칙만 있어 플레이어가 히로인을 *관리*하게 된다. 첫 질투를 “의식하기 시작함”으로 만들면 질투가 관계를 *여는* 장치가 된다 |
| 히로인끼리 싸우지 않는다 | 라이벌 히로인을 악역으로 만들면 그 히로인 루트를 아무도 안 탄다. 세 사람 모두 좋은 사람이어야 고르기가 어렵다 |
| 대답 미루기 | 하렘물의 핵심 쾌감(모두가 나를 좋아함)을 *대가가 있는 선택*으로 만든다. 미루면 서운함이 있고, 2/14에 정산된다 |
| 한 명 루트와 여러 명 루트를 둘 다 정식으로 | 하렘물 미연시의 핵심 쾌감은 *여러 명과 실제로 사귈 수 있다*는 것이다. 다만 이 게임의 주제(“자기 이름으로, 정직하게 말하기”)에 맞춰 **털어놓고 합의한 하렘만** 보상한다. 숨긴 양다리는 실패 경로다 |
| 하렘의 비용은 시간 | 연인마다 7일 멀어짐 · 불공평 이벤트. 벌점이 아니라 *모자란 칸*으로 어렵게 만들어, 하렘 루트가 한 명 루트보다 쉬운 길이 되지 않게 한다 |
| 「공정위원회」 | 아무와도 사귀지 않고 셋에게 정직한 결말도 남긴다. 고르지 않는 것도 하나의 선택이다 |
| 「빈 객석」 | 양다리·얼버무림에 확실한 끝이 있어야 하렘 루트가 긴장된다. 단, 폭력적 배드 엔딩은 쓰지 않는다 |
| 나리의 질투는 라디오로만 | 진 히로인의 비밀(루나)과 하렘 장치를 하나로 묶는다. 정체를 아는 플레이어만 들을 수 있는 질투 |

## 4. 한나리를 진 히로인으로 바꾼 이유

- 한나리는 **실용음악과 보컬**이다. 음악 · 무대 · 목소리라는 이 게임의 정서를 가장 직접적으로 몸에 지닌 인물이라, 진 히로인으로 두면 캠퍼스 생활과 라디오가 한 사람에게 모인다.
- 원본 세계의 라디오 「아쿠아 루나」는 *얼굴 없는 목소리*의 이야기였다. 나리는 *목소리가 유명한데 말을 못 하는 사람*이다. 둘을 겹치면 “무대 위에선 노래만, 라디오에선 말만 하는 사람”이 된다. 한 사람이 두 반쪽을 하나로 합치는 것이 진 엔딩이다.
- 나리의 원래 루트(떨리는 손 · 첫 줄 · 원래 가사 · 맨 앞줄)는 이미 완성도가 높아서, 진 히로인 루트의 *봄·가을*로 그대로 쓸 수 있다. 새로 쓴 것은 *루나라는 비밀*, *기획사 제안*, *어머니*, *겨울*이다.

## 5. 하지 않은 것과 이유

| 하지 않은 것 | 이유 |
|---|---|
| 필수 경영 · 반복 클릭 알바 | 가장 많이 비판받는 지점 |
| 진행을 막는 호감 관문 | 장 반복 부담 |
| 되돌릴 수 없는 관계 파탄 | 멀어짐은 약하게, 관계는 영구히 깨지지 않음(빈 객석 결말 제외) |
| 하렘을 강요하는 진행 | 하렘은 선택이다. 한 명 루트만으로도 모든 히로인의 연인 결말과 진 엔딩을 볼 수 있다 |
| 히로인에게 옷을 입히는 옷장 | 1인칭과 맞지 않음. 옷은 선물로(그림 준비 뒤) |
| 진 히로인을 처음부터 잠금 | 진 히로인은 **어려운 것**이지 **못 만나는 것**이 아니다. 개강 첫 주부터 만날 수 있다 |
