# 11. 아트와 사운드

## 1. 시각 기준

- **톤**: 밤의 남색 + 달빛의 은색 + ON AIR 빨강 한 점 + 무대 조명의 분홍. 낮 장면은 부드러운 하늘색과 따뜻한 햇빛.
- **시점**: 1인칭. 히로인은 화면 정면에서 플레이어를 본다. 플레이어의 몸은 그리지 않는다.
- **여러 명 배치**: 2인은 좌·우, 3인은 좌·중·우. 말하는 사람이 앞으로 반 걸음 나온다.
- **서체**: 대사·제목은 고운바탕, 메뉴는 Pretendard(OFL).

## 2. 히로인 그림 명세

서진의 현재 제작물은 [의상 6벌](15_히로인_의상_이미지.md#3-백서진--현재-6벌)과 [v5 제작 기록](../docs/seojin-redesign-v5.json)을 기준으로 한다. 아래의 공통 표정 확장 계획과 현재 제작된 기본 스프라이트를 구분한다.

| | 한나리 | 오다은 | 백서진 |
|---|---|---|---|
| 인상 | 사슴상의 맑은 눈과 토끼상의 부드러움. 무대 위 강렬 / 무대 밖 조용함 | 둥근 볼과 부드러운 눈매, 맑고 청순한 미소 | 여우상 눈매, 도도한 눈맞춤, 성숙한 여유 |
| 머리 | 분홍 브릿지가 있는 웨이브, 어깨 길이 | 갈색 어깨 길이 레이어드 머리, 아이보리 머리핀 | 긴 흑갈색 생머리. 근무·여름에는 낮고 긴 포니테일 |
| 평소 옷 | 밴드 티셔츠 + 가죽 재킷(무대) / 큰 후드 + 모자(무대 밖) | 하늘색 후드 + 청바지, 주황 손목밴드 | 블랙 가죽 라이더·딥 틸 톱·차콜 데님 / 검정 상의·짙은 청록 앞치마 |
| 소품 | 기타 피크(손가락 사이), 뒷주머니 수첩, 이어폰 한쪽 | 드럼 스틱, 휴대폰 | 가는 금색 귀걸이·시계, 근무용 행주, 비닐우산 |
| 상징색 | `#e89fb5` | `#f0b27a` | `#8fd1c4` |
| 표정 (최소) | 담담 · 미소 · 놀람 · 쓸쓸함 · 수줍음 · 활짝 + **무대 웃음** · **질투** | 같음 + 질투 | 같음 + 질투 |

- 1차: 인물마다 상반신 1벌 × 표정 8종. 나리는 무대 옷/무대 밖 옷 2벌. 2차: 계절 옷(여름·겨울) · 데이트 옷.
- **의상 그림**: 초기 참고안과 현재 적용된 다은·서진 스프라이트는 [15 히로인 의상 이미지](15_히로인_의상_이미지.md)에 구분했다. 기존 참고 이미지는 옷만 참조하며 `assets/미사용/`의 그림은 쓰지 않는다.
- 표정 태그: `smile`·`happy`·`shy`·`sad`·`surprised`·`neutral`·`stage`(나리)·`jealous`. 파일 이름: `assets/heroines/<id>/<옷>-<표정>.png`.
- **CG (이벤트 그림) 우선순위**: ① 입학식 무대 뒤 계단의 나리 ② 강물 위의 콧노래 ③ 가을 축제 맨 앞줄 ④ 성탄 강변 ⑤ 첫눈의 서진 ⑥ 종강 골목의 다은 ⑦ 발렌타인 셋(하렘) ⑧ 진짜 달의 첫 방송.

## 3. 배경

스팀 조사 반영 활동에 필요한 자산은 장소별로 따로 추적한다. 작곡 노트의 선택 카드·텍스트, 사연 작성과 ON AIR 표시를 첫 검증용 UI로 준비하고, 카페 주문 카드·강변 사진은 이후 확장 후보로 둔다. 사진·음원은 실제 자산과 사용 권리를 확인하기 전까지 완성된 콘텐츠로 세지 않는다. 캐릭터 그림을 근무 중인 플레이어의 대역으로 쓰지 않는다. [14장](14_개인활동_선택형체험.md)

| 장소 | 상태 |
|---|---|
| 한강변 (아침·오후·노을·밤) · 강변 카페 · 학생식당 · 동아리방 · 옥상 정원 · 공연장 | 기존 그림 재사용 가능(시간대별) |
| 내 방 · 강의실 · 도서관 · 방송국(조정실·부스) | 새로 필요 |
| 연습실 · 노래방 「3번 방」 · 학생회관 비상구 · 녹음실 | 새로 필요 |

## 4. 사운드

- 배경음(가안): 캠퍼스 낮 · 카페 · 강변 밤 · 라디오(피아노) · 합주실(드럼·기타 루프) · 하렘 코미디(경쾌한 피치카토).
- **나리의 노래**: 「계단은 무대보다 높다」 (원래 가사 / 바꾼 가사 두 판), 「관객 한 명」 짧은 판, 진짜 달의 방송 노래. 녹음이 가능하면 보컬 우선.
- **내 멜로디**: 첫 만남 강의실에서 들리는 피아노 멜로디. 18회 루나의 콧노래와 같은 멜로디여야 한다(가장 중요한 음악 복선).
- 음성을 녹음한다면 **루나의 오프닝·클로징**부터. 나리 성우는 *말하는 목소리*와 *노래하는 목소리*가 다른 사람처럼 들려야 한다.
- 효과음: 대사 넘김, 선택, 메시지 도착, ♡, 질투(작은 유리 금), ON AIR.
