# 04. 플레이 흐름과 시간

[전체 GDD 목차](README.md) · 기준일 2026-10-07 · v0.1

## 기본 순환 — 구현

`하루 시작 → 자원·이야기 조건 확인 → 일 / 휴식 / 외출 준비 → 대화와 선택 → 관계·추억 기록 → 구매·코디·수첩 감상 → 다음 날`

열린 주요 이야기는 관계 화면에서 읽는다. 이야기 읽기와 체험에는 별도 행동 칸이 들지 않는다. 진행 중인 대화나 체험이 있으면 다른 날짜·활동으로 진행하는 것을 제한하여 장면의 날짜와 코디를 보존한다.

## 시간과 회복 — 구현

| 항목 | 규칙 |
| --- | --- |
| 시작 | 1일째, 행동 칸 3, 기력 100 |
| 하루 행동 칸(AP) | 3칸. 수업·왕복 통학을 제외한 자유 시간의 추상화. 활동마다 정해진 양 소모 |
| 시간대 | 남은 칸 3 / 2 / 1 / 0 = 아침 / 오후 / 노을 / 밤 |
| 휴식 | 행동 칸 1 소모, 기력 35 회복 |
| 다음 날 | 행동 칸 3으로 초기화, 기력 60 회복, 하루 데이트 제한 초기화 |
| 기력 상한 | 100 |
| 데이트 횟수 | 하루 1회 |
| 무료 관리 행동 | 구매·착용·갤러리·기록 열람은 행동 칸을 쓰지 않음. 구매에는 상품 비용 발생 |

시간은 실제 시계와 연동하지 않는다. 두 사람은 각자 집에서 통학하며, 시계는 진행 구간을 보여 준다. 버스 노선·실측 이동 분·교통비 자동 차감은 구현하지 않는다. 대본에서 귀가 교통편을 확인하고 짧은 만남을 잡는다. 평일 첫 활동으로 학식 점심을 고를 수 있고, 카페는 수·금·토 4시간, 행사는 토·일 8시간이며 근무·납품은 하루 한 번이다. 긴 현장 근무일에는 외출을 잡지 않고, 공연과 근무도 날짜를 나눈다. 다음 날로 넘길 때 남은 행동 칸은 이월되지 않는다. 자동 관계 감쇠, 파산 엔딩, 일정 기간 후 강제 엔딩은 현재 없다. 저장 규칙상 날짜 상한은 9,999일이며 서사상 마감일과는 다르다.

## 첫날 진행 예시

다음은 현재 규칙으로 가능한 예시이며 강제 튜토리얼 순서는 아니다.

1. 관계 화면에서 `친구가 기다리는 연습실`을 읽는다. 자원 변화 없음.
2. 평일 첫 활동으로 학식을 함께 먹는다. 식권 2장 10,000원, 자금 70,000원, 남은 시간 2칸, 기력 95.
3. 학식 세 장면을 마치면 하루 외출 1회가 기록된다. 이날 다른 데이트는 잡지 않는다.
4. 미리 맡은 영상 편집 한 건을 납품하면 75,000원을 정산한다. 자금 145,000원, 시간 1칸, 기력 60.
5. 휴식하면 남은 시간 0칸, 기력 95. 다음 날로 넘기면 시간 3칸, 하루 외출 제한 초기화.

휴식은 이미 기력이 100이거나 남은 시간이 없으면 실행할 수 없다. 외출 완료 전에는 다른 경제 행동이나 날짜 이동을 할 수 없다.
