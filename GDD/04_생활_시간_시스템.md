# 04. 플레이 흐름과 시간

[전체 GDD 목차](README.md) · 기준일 2026-10-07 · v0.1

## 기본 순환 — 구현

`하루 시작 → 자원·이야기 조건 확인 → 일 / 휴식 / 외출 준비 → 대화와 선택 → 관계·추억 기록 → 구매·코디·수첩 감상 → 다음 날`

열린 주요 이야기는 관계 화면에서 읽는다. 이야기 읽기와 체험에는 별도 행동 칸이 들지 않는다. 진행 중인 대화나 체험이 있으면 다른 날짜·활동으로 진행하는 것을 제한하여 장면의 날짜와 코디를 보존한다.

## 시간과 회복 — 구현

| 항목 | 규칙 |
| --- | --- |
| 시작 | 1일째, 행동 칸 3, 기력 100 |
| 하루 행동 칸(AP) | 3칸. 활동마다 정해진 양 소모 |
| 시간대 | 남은 칸 3 / 2 / 1 / 0 = 아침 / 오후 / 노을 / 밤 |
| 휴식 | 행동 칸 1 소모, 기력 35 회복 |
| 다음 날 | 행동 칸 3으로 초기화, 기력 60 회복, 하루 데이트 제한 초기화 |
| 기력 상한 | 100 |
| 데이트 횟수 | 하루 1회 |
| 무료 관리 행동 | 구매·착용·갤러리·기록 열람은 행동 칸을 쓰지 않음. 구매에는 상품 비용 발생 |

시간은 실제 시계와 연동하지 않는다. 다음 날로 넘길 때 남은 행동 칸은 이월되지 않는다. 자동 관계 감쇠, 파산 엔딩, 일정 기간 후 강제 엔딩은 현재 없다. 저장 규칙상 날짜 상한은 9,999일이며 서사상 마감일과는 다르다.

## 첫날 진행 예시

다음은 현재 규칙으로 가능한 예시이며 강제 튜토리얼 순서는 아니다.

1. 관계 화면에서 `친구가 기다리는 연습실`을 읽는다. 자원 변화 없음.
2. 카페 아르바이트를 한다. 자금 125,000원, 남은 시간 2칸, 기력 80.
3. 기본 후드를 입고 무료 부두 산책에 출발한다. 자금 125,000원, 남은 시간 1칸, 기력 70.
4. 세 장면의 선택을 마친다. 기본 호감 +3·신뢰 +4에 선택별 추가 보상 적용. 앨범에 첫 만남 기록.
5. 휴식하면 남은 시간 0칸, 기력 100. 다음 날로 넘기면 시간 3칸, 하루 외출 제한 초기화.

휴식은 이미 기력이 100이거나 남은 시간이 없으면 실행할 수 없다. 외출 완료 전에는 다른 경제 행동이나 날짜 이동을 할 수 없다.
