# 10. 아트·사운드·에셋 명세

[전체 GDD 목차](README.md) · 기준일 2026-10-07 · v0.1

달빛, 강변, 차분한 일상과 인물 표정을 중심으로 표현한다. 현재 배경은 5개 장소 계열의 12장과 실내 UI 전용 2장, 캐릭터는 30장으로 총 44개 그림을 사용한다. 탐방 코스는 기존 배경을 공유한다. 신규 의상 8종은 기본 표정만 지원한다.

제목·대사는 고운바탕, 메뉴·선택지·수치는 Pretendard를 사용한다. 폰트와 라이선스는 로컬에 포함한다. 배경음은 선택적으로 켜는 Web Audio 합성음이며, 정식 음원·캐릭터 보이스 제작 범위는 미정이다.


## 시각 기준

현재 CSS 기준으로 어두운 청색 바탕 `#0b1522`, 밝은 본문 `#eef0ef`, 보조 글자 `#a9bbc6`, 민트 강조 `#c1e1da`를 사용한다. 반투명 패널 위에 텍스트를 놓고 배경과 인물은 보조 그림으로 제공한다. 서체 정의는 `src/typography.css`, 기본 색상은 `src/style.css`가 기준이다.

| 차콜 후드 | 차분함·미소·생각에 잠김·수줍음·놀람 |
| 니트·코트·기존 플리츠 스커트 | 차분함·미소·생각에 잠김 |

대화 첫 장면은 보통 기본 표정, 악보·결정권·회복 사건은 생각에 잠긴 표정, 다음 장면은 미소를 요청한다. 해당 의상이 지원하지 않으면 같은 의상의 기본 표정으로 표시한다.

## 실내 UI 배경

수련의 방은 입사 전의 소박한 생활 공간으로, 옷장과 예산 계획 창 뒤에 표시한다. 별도 스케줄 화면 제작 시에도 사용할 수 있다. 옷장·상점 피팅 배경은 중앙을 비워 현재 인물·의상을 합성한다. 이야기상의 장소나 데이트 기록은 바꾸지 않는다. [설정 해석·생성 프롬프트](../docs/INTERIOR_BACKGROUNDS_2026-10-07.md).
