# Aqua Luna Ver2 · GDD 통합 목차


> 2026-10-22 설정 확정: **실용음악과 보컬 전공 · 좋아하는 장르와 주로 부르는 장르는 발라드**. 대학편 과제는 발라드 보컬 앙상블·가사 해석·보컬 데모 청취 쇼케이스로 구성한다. 장기 대학편 초안과 실제 실행 대본의 범위는 [개편 기록](../docs/BALLAD_SETTING_2026-10-22.md)을 따른다.
**Aqua Luna · 수련과 보내는 하루**의 전체 기획을 정리하는 폴더다. 수련이 버츄얼 아이돌 연습생이 되기 전 대학에 다니던 시절, 같은 전공·같은 학년에서 친해진 플레이어와 함께 보내는 일상을 다룬다.

**2026-10-11 대학 시절 개편:** 사용자 확정 관계를 반영한 [한 학기 스토리라인](17_대학시절_스토리라인.md)과 [메인 시나리오 18장면](시나리오/10_대학시절_메인_시나리오.md)을 작성했다. 학년·사건은 집필 가안이며 게임 코드에는 아직 반영하지 않았다. 아래 구현 수량과 기존 대본은 현재 실행본 기준이다.

| 항목 | 기준 |
| --- | --- |
| 문서 버전 | v0.1 |
| 기준일 | 2026-10-07 (Asia/Seoul) |
| 범위 | 게임 개요, 세계관·캐릭터, 전체 스토리, 시스템·밸런스, UI·아트·음향, 기술·저장, 전체 콘텐츠·대본, QA·개발 계획 |
| 게임 상태 | 플레이 가능한 구현 있음. 장기 재미·30시간 목표·출시 검증은 미완료 |
| 근거 | 현재 `src/` 코드와 최신 과거편 구현 보고서 |

**설정**은 최신 기록에 명시된 방향, **구현**은 현재 코드에서 확인한 기능, **목표**는 아직 검증되지 않은 지향점, **미정**은 후속 결정이 필요한 내용이다. 경제 수치는 현재 구현값이지만 임시 밸런스다. 이 문서 정리가 새로운 설정·기능의 승인이나 구현을 뜻하지 않는다.

## 처음 읽는 순서

게임을 이해하려면 01 게임 개요 → 02 세계관·캐릭터 → 03 스토리·관계 → 04~08 플레이 시스템 순서로 읽는다. 실제 대사 검토는 시나리오 폴더, 수치 확인은 15 전체 콘텐츠 목록을 사용한다.

## 문서 관리 원칙

이 폴더는 현재 게임 기획의 시작점이다. `docs/`에는 과거 조사·초안·제작 보고서를 보존하고, `qa/`에는 검사 로그와 화면을 보존한다. 과거 문서의 ‘스토리 미구현’, ‘매니저’, ‘3개 데이트’ 같은 설명을 현재 설정으로 되돌리지 않는다. 근거 자료의 위치는 14번 문서에 모았다.

기획을 변경하면 관련 시스템 문서와 콘텐츠 목록·대본을 함께 갱신한다. 현재 구현과 새 제안이 다르면 각각의 상태를 명시한다. 코드가 GDD Markdown을 직접 읽는 구조는 아니므로 문서 수정만으로 게임 내용은 바뀌지 않는다.
