# 목표 진행 현황

## 유지 중인 전체 목표

**@GameFinder 고 퀄리티 연애 시뮬레이션 게임 제작**

브라우저용 텍스트 연애 시뮬레이션으로 구현합니다. Aqua Luna GDD의 수련과 세계관을 바탕으로 하되, 스토리·시나리오는 사용자가 직접 논의해 정한다는 지시를 유지합니다. 현재 시스템 프로토타입을 전체 게임의 완료로 간주하지 않습니다.

## 현재 증거

| 요구 | 현재 상태와 증거 |
| --- | --- |
| 원작 세계관·수련 설정 | `docs/SOURCES.md`에 원본 파일과 사용한 설정을 기록. 원본 폴더 변경 없음 |
| 텍스트·선택지 중심 브라우저 게임 | `index.html` + DOM UI. 별도 설치 없이 로컬 실행. PC 1424px/모바일 390px에서 클릭 경로 검증 |
| 주인공이 수입을 얻음 | 일하기 3종과 시간·기력·소지금 전이. 엔진 및 UI 테스트 통과 |
| 수련 의상 및 데이트 비용 지출 | 의상 구매·보유·텍스트 착용, 유료/무료 데이트, 신뢰 제한. 중복 차감 및 잔액 부족 방지 검증 |
| 경제 계획을 통한 장르 경험 | 저축 목표, 부족 금액, 실제 실행 조건, 행동 전후 자원 비교 구현. 기존 저장 호환성 검증 |
| 읽기 편의·저장 | 본문 크기 3단계, 설정 유지, 자동/수동 저장. 21px PC 및 모바일 UI 검증 |
| 유명 연애 시뮬레이션 참고 | GameFinder 연결 실패. KONAMI 공식 시스템 자료를 대체 확인하고 출처 기록 |
| 스토리 공동 기획 | **미완료**. 주인공 역할과 초기 관계 질문에 대한 답변 대기. 확정 대사·사건·고백·엔딩 미포함 |
| 장기 진행의 재미와 완성도 | **미완료**. 현재 3개 일거리·3개 데이트·3개 의상의 임시 경제 데이터. 시나리오·관계 단계·장기 목표 및 밸런스는 공동 기획에 맞춰 확장 필요 |
| 최종 출시 검증 | **미완료**. 실제 기기/음향/접근성 검증 및 콘텐츠를 포함한 처음부터 끝까지 플레이는 아직 불가 |

## 이번 목표 턴의 분류

진행(progress). 작업 트리에 저축 목표와 읽기 설정을 추가하고, 관계 최대치에서 잘못된 증가량 알림을 수정했습니다. 엔진 테스트 17개 및 PC/모바일 UI 시나리오가 통과했습니다. 목표 완료 상태는 선언하지 않았습니다.

## 다음 결정

사용자에게 물은 주인공 역할·수련과의 초기 관계가 정해지면, 그에 맞춘 이야기 구조와 진행 기간, 수입원, 만남·데이트의 구체적 흐름을 함께 설계합니다. 답변이 없다는 것을 설정 승인으로 해석하지 않습니다. 시나리오와 결말의 공동 기획 없이 전체 목표를 완료 처리하지 않습니다.
