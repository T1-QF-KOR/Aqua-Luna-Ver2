`하루 시작 → 남은 시간·기력·소지금 확인 → 일 / 휴식 / 데이트 선택 → 텍스트 결과와 수치 변화 → 의상 구매·착용 → 다음 날`

선택지 버튼을 눌러 활동을 수행하는 방식입니다. 비주얼 노벨처럼 대사를 순서대로 넘기는 선형 진행은 없습니다. 보조 그림은 끌 수 있습니다. 날짜는 가상의 1일째부터 시작하며 실제 달력과 연결되지 않습니다.

의상: 차콜 후드 기본 보유, 아이보리 니트 120,000원, 네이비 코트 220,000원, 가디건·플리츠 스커트 160,000원. 별도 소품은 검은 스타킹 18,000원, 살색 스타킹 16,000원입니다. 한 번 구매하면 영구 보유하며 자동 착용하지 않습니다. 옷장에서 직접 입히며 비용·시간은 들지 않습니다. 의상 구매 자체에는 호감 보상이 없습니다. 추가 의상은 원작 확정 설정이 아닌 게임용 디자인입니다.

치마 의상에 스타킹 미착용/검은색/살색을 선택하면 각각 다른 생성 이미지로 바뀝니다. 바지 의상으로 변경하면 스타킹은 미착용으로 전환되고 보유 상태는 유지됩니다. 데이트 준비창에서 보유한 코디를 다시 선택할 수 있으며, 출발 시 의상 변경·자원 차감·관계 변화·추억 기록을 함께 확정합니다. 취소와 실패는 기존 상태를 그대로 유지합니다.

배경은 부두·카페·공연장·연습실·옥상 5종입니다. 데이트 장소 3곳에 각각 다른 배경을 적용하며, 일과 휴식에도 대응 장소를 표시합니다. 추억 앨범은 최근 60회 데이트의 날짜·장소·의상·스타킹을 별도로 보관합니다. 표정 갤러리는 기본 사복의 차분함·미소·생각에 잠김 3종을 제공합니다. 스토리에 따른 표정 자동 전환은 시나리오 협의 이후 정합니다.

휴식은 시간 1칸으로 기력 35 회복. 다음 날은 시간 3칸, 기력 60 회복(최대 100). 다음 날로 넘어갈 때 남은 시간은 사라집니다. 호감·신뢰는 각각 0~100입니다. 프로토타입에는 자동 감쇠·파산·강제 엔딩이 없습니다.

## 이야기와 시스템의 경계

### 돈을 모으는 과정의 가시성

- 미보유 의상 또는 유료 데이트 하나를 저축 목표로 지정할 수 있습니다. 설정·변경·해제에 비용이나 시간이 들지 않습니다.
- 현재 자금 / 목표 비용, 부족 금액, 준비 비율을 확인합니다. 다른 활동에서 돈을 쓰면 준비 비율도 감소합니다.
- 예산 준비와 실행 가능 여부는 별개입니다. 예산이 있어도 시간·기력·신뢰·하루 데이트 횟수 제한을 지켜야 합니다.
- 해당 구매나 데이트를 실제 완료하면 목표가 해제됩니다. 그전에는 다음 날과 저장·불러오기에도 유지됩니다.
- 일하기·의상 구매는 자원 전후 비교 표, 소품 구매는 비용·잔액, 데이트 준비는 비용·시간·기력과 출발 후 잔액·관계 수치를 표시합니다. 미리보기와 취소는 상태를 변경하지 않습니다.
- 관계 수치 상한에서 활동 결과에 표시하는 증가량은 실제 적용값입니다. 이미 100이면 +0으로 표시됩니다.

### 읽기 편의

본문 크기 기본 15px / 크게 18px / 아주 크게 21px. 활동 기록과 설정 예문에 즉시 반영되며 관련 설명도 함께 확대됩니다. 글자 크기는 브라우저 환경 설정으로 저장하여 게임 진행을 불러와도 유지합니다. 본문 영역은 자체 스크롤, 긴 메뉴는 모달 스크롤로 제공합니다.

### 공동 기획 대기 항목

- 현재 활동 결과는 일반적인 시스템 알림입니다. 수련의 대사, 고백, 개인적 사건, 엔딩을 대신하지 않습니다.
- 수련의 선택·반응·성격을 표현하는 시나리오는 협의 후 데이터로 추가합니다.
- 관계 단계·연애 성립·고백 조건·선호 의상 보너스 등은 미확정입니다.
- 주인공은 원작에서 매니저입니다. 새 게임에서도 유지할지, 별도 직업을 가질지는 사용자 논의 대상입니다. 현재 일거리는 경제 검증용입니다.

## 기술 경계

`data.js`는 콘텐츠, `engine.js`는 부작용 없는 상태 전이, `app.js`는 DOM 렌더링을 담당합니다. 거래는 단일 상태 전이 안에서 검증 후 적용되므로 부분 차감이 발생하지 않습니다. 자동 저장 실패 시 현재 플레이를 유지하고 파일 백업을 안내합니다. 저장 데이터에는 버전, 범위, 보유 의상, 수입·지출 등식을 검증합니다.

저축 목표는 버전 2 저장의 선택 필드로 추가했습니다. 이전 버전 2 데이터에 필드가 없으면 목표 없음으로 불러옵니다. 없는 의상·무료 데이트·이미 보유한 의상을 목표로 지정한 손상 데이터는 거부합니다.

옷장 확장도 버전 2와 호환됩니다. `ownedAccessories`, `legwear`, `location`, `memories`가 없는 과거 저장은 소품 미보유·미착용·연습실·빈 앨범으로 보완합니다. 미보유 스타킹, 바지와 스타킹의 잘못된 조합, 없는 장소, 손상된 추억은 검증 단계에서 거부합니다.

### 저장 실패와 파일 이동

자동 저장의 성공 여부를 플레이 상태와 구분합니다. 실패한 동안에는 현재 세션을 메모리에 유지하고, 타이틀의 이어하기도 해당 세션을 사용합니다. 파일 백업 버튼이 있는 지속 안내를 표시하고, 미저장 상태에서 창을 떠날 때 브라우저 기본 확인을 요청합니다. 브라우저가 종료되기 전까지의 보호이며 영구 저장을 보장하는 기능은 아닙니다.

파일 가져오기는 크기·JSON·저장 규칙 검증 후 별도 확인을 받아 적용합니다. 읽기 도중 가져오기 창을 닫거나 다른 메뉴로 이동하면 결과를 폐기합니다. 실패한 파일 선택도 초기화하여 동일 파일을 고친 뒤 다시 선택할 수 있습니다. 알림은 열린 모달 안에 표시하여 가려지지 않습니다.

## 시간대·외형 확장 (2026-10-05)

남은 행동 칸 3/2/1/0을 아침/오후/노을/밤으로 표시합니다. 2칸 행동은 두 시간대를 전진하며, 다음 날에는 아침으로 복귀합니다. 실제 시계나 자동 시간 경과는 없습니다. 구매·착용·갤러리 열람은 시간을 사용하지 않습니다. 행동 칸이 0이면 밤 풍경을 감상하고 다음 날로 넘깁니다.

데이트 준비는 출발 시점 배경을 보여주고, 완료하면 현재 시점 배경으로 전환합니다. 앨범의 선택 필드 `time`에 출발 시간대를 보존합니다. 이전 앨범에 시간이 없으면 `시간 기록 없음`과 종전 기본 배경을 표시하며 가상의 과거 시간을 만들지 않습니다. 알 수 없는 시간 값은 저장 검증에서 거부합니다.

신규 셔츠 100,000원, 블라우스 150,000원은 임시 가격입니다. 두 의상은 바지 세트이며 기존 스타킹 호환 규칙을 지킵니다. 갤러리는 미구매 의상도 볼 수 있지만 구매·착용 상태를 변경하지 않습니다. 없는 표정 요청은 해당 의상의 기본 표정으로 돌아가며 다른 옷으로 바꾸지 않습니다.
