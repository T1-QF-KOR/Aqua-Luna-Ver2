# 수련 루트 · 공동 기획을 위한 논의안

> 2026-10-21 설정 개편: 실용음악 전공·통기타·인디 어쿠스틱은 사용자 확정. 대학편 과제는 송라이팅·합주·데모 청취 쇼케이스로 해석한다. 장기 대학편 초안과 실제 실행 대본은 구분하며 현재 반영 범위는 [개편 기록](../docs/ACOUSTIC_SETTING_2026-10-21.md)에 따른다.

이 문서는 구현된 스토리가 아닙니다. 사용자와 먼저 논의한 뒤 계획한다는 요청에 따라, 확정된 원작 정보와 선택할 항목을 나누어 둔 회의 자료입니다. 아래 대안은 채택되지 않았고 게임 내 시나리오 데이터로 사용하지 않습니다.

## 이미 정해진 기반

- 현대 서울, 망원동 Ansiro Entertainment와 달빛 부두.
- Ver2의 수련은 엔터테인먼트 입사 전, 통기타와 인디 어쿠스틱 중심의 실용음악 전공생.
- 실기 평가와 자작곡 사이의 자기 회의, 차분함과 깊은 감수성, 말보다 행동으로 감정을 표현하는 성격.
- 통기타·인디 어쿠스틱·조용한 카페라는 취향.
- 플레이어가 행동을 고르는 텍스트 게임. 수입을 의상·데이트 비용에 사용할 수 있음.

## 먼저 정할 한 가지: 주인공과 수련의 출발점

| 논의 대안 | 원작과의 관계 | 경제 시스템에 생기는 차이 |
| --- | --- | --- |
| 신입 매니저로 처음 만남 | 원작 플레이어 역할을 유지 | 급여·추가 업무가 중심. 회사 자금과 개인 데이트 자금을 구분할지 논의 |
| 매니저지만 이미 알고 지내는 사이 | 원작 역할을 유지하되 이전 관계는 새로 합의 필요 | 업무 관계와 개인적 관계가 어디서 바뀌는지 설계 필요 |
| 기획사 밖의 일반인으로 만남 | 원작을 바탕으로 한 별도 각색 | 아르바이트·직업 성장 중심. 수련과 자연스럽게 만나는 계기부터 논의 |

기존 질문의 답변을 받으면 이 표에서 하나를 선택하거나 다른 출발점을 정합니다. 답변 부재를 첫 번째 대안의 승인으로 처리하지 않습니다.

## 이후에 함께 결정할 항목

1. **관계의 속도**: 낯선 사이부터 쌓을지, 신뢰가 있는 상태에서 시작할지. 플레이어 호감 수치와 수련의 의사를 어떻게 구분할지.
2. **플레이 기간**: 짧은 계절 이야기인지, 원작의 장기 활동 기간을 따를지. 현재 '1일째' 표시는 시스템용 임시 달력입니다.
3. **데이트의 구성**: 초대 → 수락 조건 → 준비/비용 → 대화 선택 → 귀가 후 관계 변화 중 어떤 단계를 플레이할지.
4. **돈의 역할**: 지출 자체보다 장소·준비·시간 확보에 의미를 둘지. 무리해서 비싼 데이트를 하는 플레이가 어떤 결과를 낳을지는 아직 정하지 않았습니다.
5. **의상의 역할**: 보유·착용 만족감만 줄지, 수련의 취향과 장소에 맞는 선택을 대화에 반영할지.
6. **개인 서사와 연애의 관계**: 경제적 제약과 자작곡 공개의 갈등을 어느 시점에 다룰지. 진로 결정을 플레이어가 대신하는 구조로 만들지는 함께 판단해야 합니다.
7. **결말**: 연애 성립, 관계 유지, 서로 다른 선택 등 어떤 결과를 다룰지. 필요한 조건과 실패 방식은 미정입니다.

## 결정 후 제작 순서

합의한 출발점을 한 문단으로 정리 → 짧은 도입 구간의 사건과 선택지를 함께 설계 → 플레이 가능한 텍스트 장면으로 구현 → 수입·의상·데이트 시스템과 연결 → 읽어 보고 캐릭터 말투와 선택 결과를 수정.

전체 줄거리를 한 번에 확정하지 않고, 사용자가 검토할 수 있는 한 구간씩 구체화하는 방식입니다.
