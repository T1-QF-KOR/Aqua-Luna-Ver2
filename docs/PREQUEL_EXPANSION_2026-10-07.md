# Ver2 과거편 · 데이트와 체험 확장

사용자 확정: Aqua Luna 세계관 유지, 플레이어는 수련의 친구, 수련의 엔터테인먼트 입사 이전. 30시간 이상 장기 플레이를 목표로 하며, 스토리와 함께 미니게임·탐색을 넣는 구성을 선택했다.

## 세계관과 관계

- 원본 `../Aqua-Luna/GDD/03_캐릭터_설정.md`의 클래식·첼로 취향, 신중한 성격, 예고 성악과와 집안의 경제 사정으로 클래식 진로를 접은 배경을 유지한다.
- 현재 플레이어는 직원이나 매니저가 아니다. 연습실은 회사 연습실이 아닌 동네 대여 연습실, 옥상은 동네 건물의 쉼터로 표시한다.
- 첫 만남, 고백, 프로필, 타이틀과 후일담을 친구 관계에 맞춰 수정했다. 내부 `acquaintances` 저장 값은 기존 저장 호환을 위해 남지만 화면에는 ‘오래 알고 지낸 친구’로 표시된다.
- 연인·친구·고백 보류를 선택할 수 있다. 새 이야기는 연애를 강요하지 않으며 친구 결말로도 마지막까지 진행된다.
- 마지막 장에서도 계약·합격·데뷔를 발생시키지 않는다. 수련이 스스로 다음 길을 고민하고 친구와 일상을 이어가는 시점에서 끝난다. 본편의 팀 활동이나 리더 역할을 앞당기지 않는다.

| 테마 | 새 코스 |
| --- | --- |

| 식탁의 온도 | 시장 간식, 빵집, 찻집, 한 끼 요리, 디저트, 도시락 메뉴, 따뜻한 국, 둘의 메뉴판 |

| 작은 음악 여행 | 버스킹, 음반 감상실, 레코드 가게, 공개 리허설, 현악 사중주, 비공개 연습 녹음, 소리 지도, 친구만의 공연 |

기존 3코스와 합쳐 51개다. 새 코스는 각 6개 선택 장면이며, 코스 고유 도입·갈등·마무리와 테마 공통 중간 장면으로 구성된다. 모든 장면이 서로 다른 대본은 아니다. 첫 선택은 대화 선호를 기록하고, 두 번째 선택은 실제 응답과 호감·신뢰 보상을 다르게 만든다.

각 테마의 서로 다른 방문 2/4/6/8곳에서 후속 이야기 한 편씩 열린다. 3·4번째 후속 이야기는 기존 관계 후일담도 마쳐야 한다. 24편을 모두 읽으면 ‘문을 두드리기 전’이 열린다. 날짜나 대기시간으로 해금하지 않는다. 같은 장소 반복으로 새 장소 조건을 채울 수 없다.

첫 방문의 선택·코디·시간은 탐방 수첩에 별도로 남는다. 앨범은 기존처럼 최근 60회만 보관하지만 첫 방문 기록은 밀려나지 않는다. 수첩의 읽기 기능은 보상을 중복 지급하지 않는다.

## 데이트 체험

48개 코스마다 3종 체험을 네 차례 반복해 복잡도를 올리는 12단계 구성이 있다. 합계 576판이며 세 방식의 **생성형 퍼즐**이다. 코스·단계로 정해지는 시드가 같으면 저장 전후 판도 같다.

| 체험 | 규칙 | 네 차례의 변화 |
| --- | --- | --- |
| 산책길 탐색 | 인접 통로로 이동, 기록을 모아 출구에 도착. 시야가 확장되며 전체 지도 펼치기도 가능 | 7/9/11/13칸 정사각 지도, 수집 3/4/5/6개 |
| 음의 조각 | 한 칸을 누르면 중심과 상하좌우의 빛이 뒤집힘. 모든 빛을 끄면 완성 | 3×3, 4×4, 5×5 보드와 섞는 수 증가 |
| 추억 카드 | 두 장씩 열어 같은 그림 찾기. 다른 두 장은 다음 선택 때 닫힘 | 6/8/10/12쌍 |

- 출발한 데이트의 ‘둘이 체험하기’, 또는 첫 방문 이후 탐방 수첩에서 시작한다.
- 다음 단계는 이전 단계 완성으로 해금한다. 완료한 판도 다시 할 수 있다.
- 체험은 자금·AP·기력을 추가로 쓰지 않는다. 대화 진행 단계도 바꾸지 않는다.
- 모든 체험은 시간 제한 없이 플레이한다. 지도에는 충분한 걸음 예산이 있으며 초과 시 되돌리기·무료 재시도로 회복할 수 있다.
- 힌트 한 수, 한 수 되돌리기, 무료 재시도와 명시적 중단을 지원한다. 힌트 사용은 완성 기록에 표시되지만 이야기 불이익은 없다.
- 매 입력을 자동 저장하고, 불러올 때 입력 이력을 다시 실행해 벽 통과·잘못된 카드·조작된 판 상태를 거부한다.
- 체험 중에는 날짜나 대화를 별도로 진행할 수 없다. 닫으면 보존, 중단하면 이번 판만 초기화, 이미 완성한 판은 유지한다.
- Arrow/WASD, Tab/Enter와 터치 버튼을 지원한다. 음악 퍼즐은 청력이나 리듬 반응속도를 요구하지 않는다.

## 30시간 목표의 상태

**30시간 이상 실제 플레이 검증은 아직 완료하지 않았다.** 576판이라는 숫자가 576개의 독립적인 수작업 사건이나 30시간 보장을 뜻하지 않는다. 내용의 상당 부분이 세 규칙의 변형이며 반복 피로도도 별도로 평가해야 한다.

현재 대본 집계는 `qa/course-content-audit.json`에 있다. 전체 선택 장면은 360개, 중복 제거한 장면 본문은 232개, 본문·모든 선택·모든 응답의 중복 제거 후 공백 제외 문자는 26,600자다. 분당 300~600자를 가정한 단순 계산은 0.74~1.48시간이다. 실제 독서 속도 조사나 한 번의 플레이시간이 아니며, 모든 분기의 문장을 합한 값이다. 텍스트만으로 30시간이라는 주장은 하지 않는다.

체험 설계 예산의 예: 탐색 평균 5분, 음악 퍼즐 평균 4분, 카드 평균 2분을 **가정하면** 각 192판의 합계가 35.2시간이다. 이는 측정치가 아니며, 힌트·숙련 플레이는 훨씬 짧아질 수 있다. 최종 30시간 판정은 각 난도와 장기 반복을 실제 플레이어가 진행한 기록을 기준으로 해야 한다. 현재 충족한 것은 장기 체험 구조와 전체 해결 가능성이다.

## 폰트와 에셋

제목·대사: 고운바탕 Regular. 메뉴·선택지·수치: Pretendard Variable. 두 폰트를 원본 그대로 로컬 포함하고 OFL 라이선스를 동봉했다. `font-display: swap`과 시스템 폰트 대체, 기존 3단계 글자 크기를 유지한다.

- [Pretendard 공식 배포](https://github.com/orioncactus/pretendard/tree/v1.3.9), `assets/fonts/PretendardVariable.woff2`, `Pretendard-LICENSE.txt`.
- [고운바탕 공식 저장소](https://github.com/yangheeryu/Gowun-Batang), `assets/fonts/GowunBatang-Regular.ttf`, `GowunBatang-OFL.txt`.

기존 42개 그림은 유지했다. 새 텍스트 코스는 기존 5개 장소 계열의 일러스트를 공유한다. 48개의 새 장소 전용 배경을 생성한 작업은 아니다. 미니게임 보드는 DOM/CSS로 그린다. Game Studio의 구조·UI·플레이테스트 지침을 적용했다. Game Development Studio의 에셋 CLI는 현 환경에서 제공되지 않아 그 CLI의 검사나 패키지 인증을 수행했다고 주장하지 않는다.

## 저장과 검증

기존 v2 저장은 새 탐방·체험 기록을 빈 상태로 보충한다. 기존 자금·의상·관계 선택을 보존하며, 이전 선택 ID는 유지한다. 기존 완료 대화도 새 과거 설정의 문장으로 다시 읽힌다. 내보내기/가져오기 제한은 장기 기록을 위해 1 MiB로 조정했다.

`tests/run-story-check.ps1`은 Chrome 전용 테스트 프로필로 엔진, 전체 루트, 실제 UI와 네이티브 키 입력을 확인한다. PC 1440px, 모바일 폭 390px 및 신규 화면 320px. 576판 모두 합법적 입력으로 해결 가능성을 검사하고, 양쪽 관계 결말에서 48곳 탐방과 최종 이야기에 도달함을 확인한다. 수첩 첫 기억이 이후 240회의 외출 뒤에도 유지됨을 검사한다. 상세 결과와 화면은 `qa/REPORT.md`와 `qa/narrative-*.txt`, `qa/activity-*.png`에 있다.

이 검사는 실제 휴대전화·Safari 확인이나 30시간 사람 플레이테스트를 대체하지 않는다.
