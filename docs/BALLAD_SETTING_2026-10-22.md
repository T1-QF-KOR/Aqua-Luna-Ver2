# 수련 보컬·발라드 설정 개편 · 2026-10-22

사용자 확정: **실용음악과 보컬 전공. 좋아하는 장르도, 주로 부르는 장르도 발라드.** 수련과 플레이어는 같은 전공·같은 학년의 대학 친구다. 차분하고 신중한 성격과 감수성, 경제적 제약, 대학 일상과 관계 분기를 이어 간다.

## 캐릭터와 이야기

좋아하는 발라드를 따라 부르며 목소리로 마음을 전하고 싶어진 수련은 보컬 입시를 거쳐 실용음악과에 입학한다. 노래를 배우는 즐거움과 실기 평가의 부담, 보컬 레슨·연습실 비용, 자기 해석이 담긴 녹음을 공개할 용기를 다룬다. 기타 연주나 작곡을 수련의 전공·주 장르를 설명하는 중심 설정으로 사용하지 않는다.

수련의 음악 이야기는 **연습실 → 보컬 노트 → 발라드 선곡과 주변의 고음 기대 → 직접 고른 곡을 부르는 작은 무대**로 이어진다. 플레이어는 수련이 원하는 표현과 공개 범위를 듣고, 수련이 선택한 뒤에 돕는다. 발라드를 좋아한다는 이유로 모든 일상 대화를 음악 이야기로 바꾸지는 않는다.

대학편 초안은 일상에서 떠올린 감정과 주변 소리를 활용하는 **3분의 발라드 보컬 앙상블 과제**와 보컬 데모 청취 쇼케이스를 사용한다. 실기 수업에서 부르는 노래와 개인적인 해석을 관객에게 공개하는 부담을 구분한다. 장기 대학편 전체를 새로 실행 코드로 옮긴 것은 아니며, 현재 실행본은 기존 42편·51코스 구성이다.

## 저장과 아트

기존 `acoustic-chords`, `acoustic-lyrics`, `acoustic-demo`, `score`, `concert`, `music-chamber`, `score-clip`, `cello-card` 등 사건·선택·선물 ID와 노드 수를 유지한다. 전용 저장 필드를 추가하지 않았다. 과거 활동 로그에 이미 저장된 문장은 당시 기록으로 남고, 현재 메뉴와 재생 대본은 새 설정을 따른다.

공연의 기존 라이브 카페 배경 `assets/environment/acoustic-live.png`를 재사용한다. 이번 변경은 텍스트·설정 개편이며 새로운 보컬 음원이나 아트는 추가하지 않았다. 이전 어쿠스틱 설정·제작 결과는 [2026-10-21 작업 기록](ACOUSTIC_SETTING_2026-10-21.md)에 보관한다.
