# 현재 개발 방향 · 2026-10-30

대화에서 사용자는 더 좋은 미연시가 된다면 기존 세계관과 구조를 바꿔도 된다고 명시했다. 기존 GDD는 출발점이며, 변경 불가능한 완성 조건으로 보지 않는다. 다만 전체 게임과 결말까지 만드는 목표는 유지한다. 일부 학기나 자동 테스트 통과만으로 전체 완성을 선언하지 않는다.

## 사용자에게 직접 확인된 기준

- 기존 UI의 완성도는 최소 기준이다.
- 일러스트는 현실풍이 아닌 애니·버추얼 화풍이며, 히로인별 추가 의상 그림을 실제로 만든다.
- 새 게임은 날짜와 대학 입학을 보여 주는 짧은 인트로로 시작한다.
- 수업 뒤 장소를 하나의 오른쪽 패널에서 고르고, 선택한 장소를 먼저 둘러본 뒤 방문한다.
- **방문 전에는 만날 사람을 표시하지 않는다.** 이름, 인물색 음표, 인물 유무를 역으로 드러내는 별도 제외한다. 이전 문서의 지도 힌트 복원 제안보다 이 직접 요청을 우선한다.
- 자유 만남은 요일·날씨·사정에 따른 확률을 사용하고 같은 시간대의 클릭·저장 복원으로 결과를 재추첨하지 않는다.

## 이번에 선택한 개선 방향

익명 라디오와 현실의 관계라는 중심 소재는 살린다. 선택의 결과는 마음 수치만이 아니라 상대가 말하는 내용, 실제 방송의 휴방, 다음에 만나는 장면으로 이어지게 한다. 봄의 반복 활동만 계속 보강하지 않고 여름, 가을, 겨울과 결말까지 플레이 구간을 연결한다.

의상 제작은 파일만 늘리는 작업이 아니라 선물의 이름, 실제 그림, 계절, 데이트 서술과 저장 복원이 맞는지까지 확인한다. 전용 표정 그림이 없는 상태에서 존재하지 않는 파일을 계속 요청하지 않는다.

현재 구현 구간과 검증 범위는 진행 보고서와 실제 실행 코드를 기준으로 확인한다. 이 문서는 전체 게임이 완성됐다는 선언이 아니다.

## 추가된 제작 기준과 하루 진행

사용자는 Steam 미연시의 장점과 재미를 조사해 실제 제작에 반영하고, 히로인 그림을 고품질로 만들어 감상하는 즐거움을 높이도록 목표를 갱신했다. 기존 조사에 공식 소개 재확인과 Our Life의 관계 속도·기억 설계를 더했다. 캐릭터 원화를 참조한 겨울 전용 CG 세 장과 실제 장면 해금·앨범 감상을 연결했다.

이어서 등교일에는 학교의 메인 이야기를 먼저 보고 수업 뒤 장소를 골라 별도 사건을 경험하는 흐름을 원했다. 일반 수업을 짧은 학교 장면으로 바꿨다. 1·2학기 각각 16주, 요일별 160개 중심 문장으로 주인공의 과제가 이어진다. 지정된 아침 사건은 우선하며 주말·공휴일·방학에는 일반 등교를 넣지 않는다. 수업이 끝나면 같은 날 오후의 오른쪽 장소 패널로 이어진다.

자유 활동은 기존 관계 사건을 우선하고, 조용한 장소에서도 수업과 연결되는 짧은 이야기를 제공한다. 선택한 작업 방향과 실제 남긴 장소 기록이 다음 수업에 돌아온다. 인물은 그 시간대 출석·위치가 확인될 때만 등장한다. 지도에 만날 사람을 미리 공개하지 않는 직접 요청은 계속 유지한다. [조사 근거와 실제 반영](../GDD/스팀_미연시_제작자료/11_학교흐름과_겨울_실제반영.md).

## 서진 전면 재설계 · 최신 사용자 요청

사용자는 서진을 여우상에 쿨하고 도도하며 성숙하고 섹시한 매력이 있는 캐릭터로 바꾸고, 얼굴형·헤어·의상까지 새로 설계하라고 했다. 기존 파스텔 블라우스·흰 스커트와 크림 카디건은 청순해 보여 마음에 들지 않으며 가죽 재킷 같은 시크한 옷을 원한다고 구체화했다.

최종 기준은 긴 흑갈색 생머리, 선명하고 길어진 얼굴선, 올라간 청록색 눈매와 여유 있는 시선이다. 기본 사복은 블랙 가죽 라이더 재킷·딥 틸 톱·차콜 데님, 여름복은 블랙 비대칭 톱·차콜 데님 쇼츠다. 근무복·블레이저·비대칭 니트·겨울 코트와 첫눈 CG까지 같은 새 인물 디자인으로 맞췄다. 카페 선배·24세·전 수영 선수·어깨 부상·다시 물로 돌아가는 진로는 새 성격과 잘 맞아 유지하고, 첫 만남·플레이리스트·일상 대화·메시지·외출·선물·갈등·진로·고백·교제 이후까지 같은 목소리로 개정했다. 관심은 먼저 말하고, 진로는 스스로 정하며, 오해는 인정하고 거절은 존중한다. [집필 기준과 적용 범위](seojin-voice-guide.md). 초기 v4 눈매 수정안은 최종안이 아니다. [선택된 그림과 정확한 프롬프트](seojin-redesign-v5.json). [설정·대사·검증 완료 기록](../reports/SEOJIN_REDESIGN_2026-10-30.md).

## 나리 의상에 대한 추가 요청 · 기록

사용자가 직접 고른 `nari-utility-cargo-v3.png`, `nari-casual-v3.png` 두 벌은 옷 자체가 마음에 들지 않아 나리에게 어울리는 디자인으로 바꿔 달라고 했다. 두 벌을 각각 블라우스·블랙 뷔스티에 원피스와 크림 카디건·라벤더 톱·데님 스커트로 교체했다. 얼굴과 머리, 분홍 포인트와 애니·버추얼 화풍은 유지한다. 이 요청을 다른 모든 후드나 바지 디자인의 금지로 확대 해석하지 않는다. [교체 파일과 프롬프트](nari-outfit-redesign-v4.json).
