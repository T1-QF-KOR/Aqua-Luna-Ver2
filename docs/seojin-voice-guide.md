# 백서진 · 현재 인물과 집필 기준

2026-10-30 적용. 사용자가 요청한 여우상·쿨함·도도함·성숙하고 섹시한 분위기를 얼굴·옷·대사·관계의 태도에 함께 반영했다.

## 인물

24세, 한여울대 체육교육과 휴학생. 강변 카페 ‘물결’에서 가장 오래 일한 교육 담당이고 사장님의 조카다. 전 수영 선수로 고2 때 어깨를 다쳤다. 어린 시절 다니던 수영장의 5번 레인은 지금 주차선이 되었다. 상대를 보는 눈은 빠르고 자기 의사는 분명하지만, 다시 물로 돌아가는 선택 앞에서는 말을 고른다.

카페 실력, 눈맞춤과 짧은 농담이 첫인상을 만든다. 상대를 깔보거나 모든 마음을 알아맞히지는 않는다. 친밀해지면 주인공이 알아채기만 기다리지 않고 먼저 시간을 청한다. 자기 진로도 자기 몫이다. 지원서를 실제로 낸 경우에만 합격·강사 취업을 이야기한다.

외형은 길고 선명한 얼굴선, 가늘게 올라간 청록색 눈, 긴 흑갈색 생머리, 옅은 미소다. 근무와 여름에는 낮고 긴 포니테일. 사복은 검정 가죽 라이더, 딥 틸 톱, 차콜 데님을 기준으로 한다. 가는 금색 귀걸이와 시계가 공통 장신구다. [최종 그림·프롬프트](seojin-redesign-v5.json), [의상 6벌](../GDD/15_히로인_의상_이미지.md#3-백서진--현재-6벌).

## 관계에 따른 목소리

| 단계 | 말과 행동 | 현재 게임 대사 예 |
|---|---|---|
| 첫 만남 | 상대의 시선을 알아채고 바로 일로 이끈다 | “구경은 쉬는 시간에. 지금은 내 손 봐. 한 번 해 줄게.” |
| 익숙한 동료 | 능숙하게 가르치고 작은 변화를 기억한다 | “매일 오니까. 네가 설탕 반 봉지만 넣는 것도 알고. 내가 별생각 없이 보는 줄 알았어?” |
| 친구·관심 | 취향을 묻고 먼저 연락한다 | “별일은 없고. 네 생각이 나서 먼저 연락했어. 이유 더 필요해?” |
| 가까운 사이 | 같이 있고 싶은 마음을 직접 말한다 | “오늘은 네가 언제 가자고 하나 보고 있었어. 나는 아직 안 가고 싶은데.” |
| 자기 진로 | 농담이 잠깐 멈추고 말의 속도가 늦어진다 | “지원하고 싶어. 여기까진 확실해. 그런데 또 안 되면… 그다음 말을 아직 못 찾겠어.” |
| 갈등 | 문제를 구체적으로 확인하고 자기 오해는 인정한다 | “너한테 먼저 따진 건 내가 잘못했어.” |
| 고백 | 확신을 갖고 먼저 말하고 답은 상대에게 맡긴다 | “나 너 좋아해. 알바생 말고, 너.” |
| 연인 | 호감을 숨기지 않고 농담 뒤에도 말을 거두지 않는다 | “왔네. 오늘은 내가 먼저 보고 싶었어. 너는?” |
| 보류·친구 | 기다림의 경계와 정리할 시간을 말한다 | “대신 기다리는 내 시간도 네가 기억해 줘.” |

짧고 낮고 건조한 말끝을 기본으로 한다. 모든 문장을 도발로 끝내지 않는다. 일할 때는 정확한 안내가 먼저이며, 친해진 뒤의 장난은 상대가 대답할 여지를 남긴다. 늘 “부끄럽잖아”, “아니, 그냥”으로 호감을 거두거나 상습적으로 바보라고 부르는 방식은 쓰지 않는다. 민망함이 있어도 무조건 화를 내거나 부정하지 않는다.

섹시함은 시선, 자신에게 맞는 옷의 선, 가까워지는 타이밍과 자기 의사에서 만든다. 장면과 관계 단계에 맞지 않는 노골적인 유혹을 반복하지 않는다. 거절을 뒤집으려고 압박하거나 주인공을 소유물로 다루지 않는다.

## 루트의 감정 변화

첫 출근의 능숙함 → 마감 음악을 나눔 → 어깨를 무리하지 않고 도움을 고름 → 우산 아래 가벼운 장난 → 재활 앞에서 초보임을 인정함 → 주차장이 된 수영장에서 자기 이야기를 시작함 → 잘못 의심한 일과 남이 정하는 진로를 구분함 → 스스로 강사 지원을 고름 → 첫눈에 먼저 고백함 → 답에 맞는 연인·친구·보류의 거리를 지킴.

‘수심 3m’는 쉽게 말하지 못한 꿈과 익명의 목소리, ‘수심 0m’는 스스로 고른 다음 시간을 나타낸다. 연애만으로 어깨나 상처가 해결됐다고 말하지 않는다. 카페의 능숙함과 수영 앞의 불안이 함께 존재한다.

## 실제 개정 범위

- `scenes.js`, `semester.js`: 첫 출근·플레이리스트·컵·우산·비 피하는 교차 장면·축제 연락.
- `dialogue.js`, `dialogue-compat.js`: 6개 일상 주제의 관계 단계와 추가 회차, 인사, 실제 추억 회상, 아직 겪지 않은 일을 아는 척하지 않는 대체 대사.
- `messages.js`, `outings.js`, `dateActivities.js`: 정기 연락·먼저 잡는 약속·지각 경계·5곳의 도착 대사·4종 외출 대화·취향 활동·외출 결과.
- `peopleEvents.js`, `smallEvents.js`, `composition.js`: 개인 사건·우연한 만남·근무·시험·방학·곡 감상.
- `summer.js`, `autumn.js`, `winter.js`: 재활·수영장·생일·충돌·진로·고백·연인·친구·보류 이후.
- `social.js`, `relationships.js`, `romance.js`, `holidays.js`, `radio.js`, `game.js`: 질투와 관계 인사·보상 대사·관계 합의·성탄 초대·선물 반응·주인공이 보는 서진.
- 인물 설정·게임 개요·아트 명세·의상 명세·백서진 대본·교차 대본의 서진 묘사.

관계 조건·실제 추억·지원 여부·기존 연인의 합의·선택 결과는 각 모듈의 조건을 따른다. 과거 저장된 로그를 새 대사로 소급 덮어쓰지는 않는다. 이미 진행 중인 장면의 저장된 큐에는 이전 대사가 남을 수 있으며, 새로 시작되는 장면부터 개정 대사를 사용한다.

## 제작 범위

[백서진 현재 루트 대본](../GDD/시나리오/06_대본_백서진.md)은 현재 실행 장면을 기준으로 정리했다. 1월 5일부터 만날 수 있는 ‘수심 1m’은 강사 지원·합격과 관계 상태를 반영한다. 서진의 연인·친구 결말 초안은 2027년 2월 26일에 연결되어 있으며, 전 분기 실플레이와 연출 개선이 남았다. 현재 스프라이트는 6벌의 기본 표정이며, 개별 표정 그림 전체를 제작한 상태는 아니다.
