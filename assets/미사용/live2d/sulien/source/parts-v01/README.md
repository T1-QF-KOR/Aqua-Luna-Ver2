# 수련 파츠 분리 초안 v01

내장 이미지 생성 도구로 원화를 참고하여 제작한 파츠입니다. 사용자가 이미지 생성 방식으로 계속 보완하도록 선택했습니다. 원본 픽셀을 잘라낸 파일이 아니므로 크기·위치·윤곽의 정렬 검수가 필요합니다.

## 파일

- `sulien-parts-v01.psd`: 8개 파츠와 숨겨진 원화 참고 레이어를 담은 PSD.
- `Body_Base.png`: 의상·팔·손·다리·신발 및 목.
- `Face_Base.png`: 눈·눈썹·입을 제거하고 피부를 보완한 얼굴 바탕.
- `Hair_Front.png`, `Hair_Back.png`: 앞머리와 뒷머리/포니테일.
- `Eye_ViewerLeft.png`, `Eye_ViewerRight.png`: 화면 기준 좌우 눈. 흰자·홍채·속눈썹은 각 눈 파일에 합쳐져 있습니다.
- `Brows.png`, `Mouth.png`: 양쪽 눈썹과 닫힌 입.
- `assembly-preview-unregistered.png`: 정렬 전 레이어 합성 미리보기. 완성 캐릭터가 아닙니다.
- `generation-prompts.json`: 사용한 생성·보완 프롬프트.
- `parts-manifest.json`: 파일 해시, 캔버스 크기, 검증 상태.

모든 PNG는 1024×1536 RGBA입니다. PSD는 별도 마스크 편집 없이 생성 PNG의 픽셀을 그대로 포장했습니다. PSD의 병합 이미지 및 각 레이어 디코딩은 확인했습니다.

## Cubism 진행 상태 (2026-10-17)

`sulien-parts-v01.cmo3`에 파츠 가져오기와 저장을 확인했습니다. 뷰 영역 상태 리셋 후 캔버스가 정상 표시됩니다. CMO3 안에서 그리기 순서와 얼굴·앞머리·뒷머리의 크기 및 위치를 조정했습니다. 원본 PNG와 PSD는 그대로입니다.

8개 보이는 파츠에 작은 변형용 메쉬를 생성하고 `Body_Sway`의 자식으로 연결했습니다. `ParamBodyAngleZ`에는 -10, 0, 10 키폼이 있습니다. 아래 기준점, 가로 0.8, 세로 0, 부드러움 3으로 설정했으며 양쪽 끝값에서 움직임을 확인했습니다. 검증 후 화면 미리보기 값은 +10입니다.

## 추가 진행 (2026-10-19)

`EyeR_Blink`와 `EyeL_Blink`에 각각 화면 왼쪽·오른쪽 눈을 연결했습니다. 두 눈 디포머는 아직 키폼 없는 준비 구조입니다. 입은 백업에서 복구하고 `Mouth_Form`의 자식으로 연결했습니다. 입 디포머도 아직 표정 키폼은 없습니다.

`HairBack_Sway`를 `Body_Sway` 아래에 생성하고 `Hair_Back`을 연결했습니다. 머리 흔들림 뒤 파라미터에 -1, 0, 1 키폼을 생성했습니다. 위 기준점, 좌우 가로 1.5, 세로 0, 부드러움 3, 확대·축소 0입니다. 양끝에서 뒷머리 변형을 화면으로 확인했고 중앙값으로 돌아와 CMO3를 저장했습니다. 몸 회전 Z와 뒷머리 미리보기는 모두 0입니다. 물리 연동은 아직 없습니다.

## 남은 작업

얼굴 경계와 세부 정렬 검수, 눈꺼풀·홍채·흰자 및 열린 입 파츠, 눈 깜빡임·립싱크·앞머리 움직임·호흡 리깅과 머리카락 물리 연동이 남아 있습니다. 런타임 아틀라스와 moc3 내보내기 및 앱 적용도 아직 하지 않았습니다.

기존 `../sulien-basic-rig.cmo3`는 단일 원화 리깅입니다. 현재 파츠 모델과 별개입니다.
