# Aqua Luna · 수련과 보내는 하루

> 2026-10-23: 통학·학식·알바·데이트와 관련 대사를 선택 적용했습니다. [적용 전후·검증 보고서](reports/CAMPUS_LIFE_APPLIED_2026-10-23.md) · [생활 대본](GDD/시나리오/13_대학생_생활_대사.md). 그 밖의 대학편 개편안은 검토 상태입니다.


> 2026-10-22 설정 확정: **실용음악과 보컬 전공 · 좋아하는 장르와 주로 부르는 장르는 발라드**. 대학편 과제는 발라드 보컬 앙상블·가사 해석·보컬 데모 청취 쇼케이스로 구성한다. 장기 대학편 초안과 실제 실행 대본의 범위는 [개편 기록](docs/BALLAD_SETTING_2026-10-22.md)을 따른다.
수련을 중심으로 하는 **스토리·데이트 체험형 연애 시뮬레이션**입니다. Aqua Luna 세계관의 과거, **수련이 버츄얼 아이돌 연습생이 되기 전 대학에 다니던 시절**을 다룹니다. 플레이어는 수련과 같은 전공·같은 학년에서 친해진 친구이며, 친구 관계를 유지하거나 연인으로 발전할 수 있습니다.

2026-10-11 대학 시절 스토리 개편: [한 학기 스토리라인](GDD/17_대학시절_스토리라인.md)과 [메인 시나리오 18장면](GDD/시나리오/10_대학시절_메인_시나리오.md)을 작성했습니다. 학년과 구체적인 사건은 집필 가안이며 **게임 코드에는 아직 반영하지 않았습니다.** 현재 실행본의 과거 설정·데이트·체험은 [구현 보고서](reports/PREQUEL_EXPANSION_2026-10-07.md)를 참고하세요.

기획 전체는 [GDD 폴더 · 전체 기획 목차](GDD/README.md)에서 확인할 수 있습니다. 게임 개요·세계관·전체 스토리·시스템·UI·아트·기술·QA를 문서별로 나누고, 모든 데이트·이야기 대본과 콘텐츠 목록을 최신 과거편 기준으로 정리했습니다.

2026-10-12 관계 시스템 보강: 하루 한 번 작은 선물로 수련의 숨은 취향을 알아 가고, ‘잠깐 이야기하기’에서 화제 3개를 골라 그날 수련의 마음을 읽으며, 지식·체력·감수성을 키우면 모든 데이트에서 특별한 선택지가 열리고, 학사 달력(1일째 = 3월 2일 개강)과 행사·수련의 생일(4월 17일)이 하루의 리듬을 만들며, 메신저 앱에서 수련·같은 과 친구 하윤·학과 알림을 주고받고, 오래 못 보면 수련의 기분이 조금씩 내려갔다가 다시 만나면 돌아옵니다. 메인 화면에서 수련을 누르면 반응하고, ‘관계 노트’에 인연 단계와 알게 된 취향이 쌓입니다. 이야기 장면에는 대사 기록·자동·건너뛰기·숨기기가 있습니다. [게임 디자인 연구](reports/DATING_SIM_GAME_DESIGN_STUDY_2026-10-12.md)

2026-10-12 연애 연출 개편: 이야기·데이트가 비주얼 노벨처럼 한 줄씩 진행됩니다. 줄마다 수련의 표정(7종)과 카메라 거리가 바뀌고, 선택하면 ♡ 호감·◇ 신뢰 변화가 바로 뜹니다. 데이트 다음 날에는 수련의 메시지가 옵니다. 연인이 된 뒤에는 ‘말 놓기’ 장면이 열립니다. [연애 연출 조사·적용 제안](reports/ROMANCE_PRESENTATION_RESEARCH_2026-10-12.md)

2026-10-19 휴대폰 UI: **휴대폰** 버튼에서 메시지·달력·능력치/일정·저축·상점·옷장·앨범·기록·일하기·데이트·이야기·관계·선물·저장·불러오기·설정 앱을 엽니다. 기능 화면과 확인창은 휴대폰 내부에서 스크롤하고, 하단 홈 막대로 앱 목록에 돌아옵니다. 이야기·데이트 본편과 대화 연출은 전체 무대에서 이어집니다. [구현·검증 기록](reports/PHONE_UI_2026-10-19.md)

**출시 방향: PC 전용 · Steam.** 모바일·태블릿 버전은 개발하지 않습니다. 현재는 로컬 브라우저 개발판이며 Steam 실행 파일과 배포 연동은 준비 단계입니다. [PC 지원 범위와 Steam 출시 준비](docs/PC_STEAM_RELEASE.md).

**데스크톱 앱(브라우저 없이 실행):** `powershell -ExecutionPolicy Bypass -File scripts/build-exe.ps1`을 실행하면 `dist/AquaLuna/AquaLuna.exe`가 만들어집니다. 더블클릭으로 바로 실행되며, `dist/AquaLuna` 폴더째 옮기거나 배포하면 됩니다(.NET 10 SDK는 빌드할 때만 필요하고 플레이어 PC에는 필요 없음). F11 또는 Alt+Enter로 전체 화면을 전환하고, 창을 1280×720보다 작게 줄이면 화면 전체를 축소해 배치를 유지합니다. 앱의 저장은 `%LOCALAPPDATA%\AquaLuna`에 남습니다. 브라우저에서 하던 진행은 **저장 → 파일 내보내기** 후 앱에서 **파일 가져오기**로 옮깁니다. 실행기 코드는 `launcher/`(WebView2)에 있습니다.

**브라우저 개발판:** `index.html`을 PC의 Chrome 또는 Edge에서 열면 됩니다. 브라우저 화면은 최소 1280 × 720, 권장 1440 × 900 이상입니다. 작은 창에서는 PC 배치를 유지하며 스크롤합니다. 모바일·태블릿은 지원하지 않습니다. 설치, 빌드, 인터넷 연결이 필요하지 않습니다. 모든 버튼은 마우스·키보드(Tab, Enter)로 사용할 수 있습니다. Esc로 열린 창을 닫습니다.

- **관계와 이야기 42편**: 관계 11편, 성장 3편, 테마 후속 24편, 마지막 1편, 발라드 보컬 제작 3편입니다.
- **선택형 데이트 52코스**: 학식 포함 기본 4곳 + 물길·책과 그림·식탁·공방·음악·도시의 48개 탐방 코스. 새 코스는 6장면, 서로 다른 방문 경험으로 다음 코스와 이야기를 엽니다.
- **데이트 체험 3종**: 산책길 탐색, 음의 조각 퍼즐, 추억 카드. 48코스 × 12단계 = **576개 생성형 체험판**. 새 대본 576편이라는 뜻은 아닙니다. 힌트·되돌리기·재시도·중간 저장을 지원하며, 체험은 결말을 막지 않는 선택 활동입니다.
- **탐방 수첩**: 48곳의 첫 대화·코디와 체험 완성 기록을 영구 보관합니다. 검색·테마·미방문·방문 완료·출발 가능 필터와 페이지 탐색을 제공합니다.
- **한글 폰트**: 제목·대사는 고운바탕, 메뉴는 Pretendard. 공식 OFL 폰트와 라이선스를 게임 폴더에 포함해 오프라인에서도 표시됩니다.
- **대화 중 저장·재개**: 비용은 출발 시 한 번 차감. 중간에 닫거나 다시 접속해도 이어 읽기. 앨범과 지난 이야기 다시 읽기는 진행을 바꾸지 않습니다.
- 기본 관계 결말은 기본 후드와 무료 산책으로 진행할 수 있습니다. 탐방 마지막 이야기는 48개 코스와 후속 이야기를 마쳐야 열립니다.
- **30시간 이상은 설계 목표이며 실측 완료가 아닙니다.** 체험 숙련도와 힌트 사용에 따라 시간이 크게 달라집니다. 텍스트만으로 30시간을 제공하는 버전은 아닙니다.

## 저장 주의사항

저장은 현재 브라우저의 `localStorage`에 남습니다. 시크릿 모드, 브라우저 데이터 삭제, 다른 브라우저·파일 경로로 이동하면 자동으로 이어지지 않을 수 있습니다. **저장 → 파일 내보내기**로 백업하면 다른 실행 환경에서 가져올 수 있습니다. 파일은 로컬에서만 처리하며 외부 서버로 전송하지 않습니다.

자동 저장이 막힌 동안에는 **현재 창 안의 진행을 유지**하며 상단에 파일 백업 버튼을 표시합니다. 타이틀로 돌아가도 현재 세션으로 이어할 수 있지만, 창을 닫거나 새로고침하면 미저장 진행을 잃을 수 있으므로 먼저 파일로 보관해 주세요. 저장이 다시 가능해지면 다음 저장 시 최신 세션을 기록하고 안내가 사라집니다.

## 검증

`tests/runner.html`에서 경제 규칙 테스트를 실행할 수 있습니다. 상세 결과와 실행 방식은 [검증 기록](reports/QA_REPORT.md)을 참고하세요.

원본 `../Aqua-Luna` 폴더는 수정하지 않았습니다. 설정 출처와 생성 이미지 프롬프트는 [출처 기록](docs/SOURCES.md)에 정리했습니다.

이전 추가 이미지 11장은 [초기 이미지 제작 기록](docs/ART_ASSETS.md), 이번 21장은 [시간대·표정 확장 기록](docs/ART_DAYTIME_EXPANSION.md)에 경로와 생성 프롬프트를 기록했습니다. 내장 이미지 생성 도구를 사용했습니다. 일부 장소·시간대는 같은 배경을 공유하며, 대화 장면에서 지원 의상의 표정을 사용하며, 지원하지 않는 조합은 의상을 보존하는 기본 표정으로 대체합니다.
