# Aqua Luna

**대학 첫해, 캠퍼스에서 세 사람과 인연을 맺는다. 그중 가장 가까이 있으면서 가장 먼 사람은 — 모두가 노래를 알지만 아무도 말을 들어 본 적 없는, 한나리다.**

서울 한강변의 가상 대학 「한여울대학교」에서 신입생 1년을 보내는 **멀티 히로인 연애 시뮬레이션(미연시)**입니다. 플레이어는 실용음악과 작곡 전공 남자 신입생이 되어 수업·알바·동아리 사이에서 시간을 쪼개고, 세 히로인을 만나고, 고르고, 때로는 놓칩니다. 매주 목요일 밤에는 정체를 숨긴 DJ ‘루나’의 학교 심야 라디오 「아쿠아 루나」를 듣습니다.

| **한나리** (진 히로인) | 실용음악과 2학년 · 밴드 보컬. 무대 밖에선 말 한마디가 어렵다. 그리고 아무도 모르는 DJ ‘루나’ | 12/24 성탄 특집 뒤 |

## 실행

**출시 방향: PC 전용 · Steam.** 모바일·태블릿 버전은 개발하지 않습니다. [PC 지원 범위와 Steam 출시 준비](docs/PC_STEAM_RELEASE.md)

**데스크톱 앱(브라우저 없이 실행):** `powershell -ExecutionPolicy Bypass -File scripts/build-exe.ps1`을 실행하면 `dist/AquaLuna/AquaLuna.exe`가 만들어집니다. 더블클릭으로 바로 실행되며, `dist/AquaLuna` 폴더째 옮기거나 배포하면 됩니다(.NET 10 SDK는 빌드할 때만 필요). F11 또는 Alt+Enter로 전체 화면을 전환합니다. 앱의 저장은 `%LOCALAPPDATA%\AquaLuna`에 남습니다. 실행기 코드는 `launcher/`(WebView2)에 있습니다.

**브라우저 개발판:** `index.html`을 PC의 Chrome 또는 Edge에서 엽니다. 최소 1280 × 720, 권장 1440 × 900 이상. 설치·빌드·인터넷 연결이 필요하지 않습니다.

## 저장 주의사항

브라우저판 저장은 현재 브라우저의 `localStorage`에 남습니다. 시크릿 모드, 브라우저 데이터 삭제, 다른 브라우저·파일 경로로 이동하면 이어지지 않을 수 있습니다. **저장 → 파일 내보내기**로 백업하면 다른 실행 환경에서 가져올 수 있습니다. 파일은 로컬에서만 처리하며 외부 서버로 전송하지 않습니다.

### 새 캠퍼스 기획 개발 빌드

**`index.html`**과 **`campus.html`**은 같은 새 기획 개발 빌드를 엽니다. 현재 플레이 구간은 6월 말까지입니다. `node tests/campus-v2.test.mjs`와 `node tests/campus-v2-runtime.test.mjs`로 핵심 규칙과 실제 게임 처리의 저장·분기 계약을 검사합니다. 이 검사는 브라우저 화면 검증 및 완성 게임의 종합 검증과 별개입니다.
