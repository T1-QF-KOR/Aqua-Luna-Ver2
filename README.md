# Aqua Luna · 수련과 보내는 하루

수련을 중심으로 하는 **스토리·데이트 체험형 연애 시뮬레이션**입니다. Aqua Luna 세계관의 과거, **수련이 엔터테인먼트에 들어가기 전**을 다룹니다. 플레이어는 수련의 오래된 친구이며, 친구 관계를 유지하거나 연인으로 발전할 수 있습니다. 최신 변경은 [과거 설정·데이트·체험 확장 보고서](docs/PREQUEL_EXPANSION_2026-10-07.md)를 참고하세요.

## 실행

`index.html`을 Chrome 또는 Edge에서 열면 됩니다. 설치, 빌드, 인터넷 연결이 필요하지 않습니다. 모든 버튼은 마우스·터치·키보드(Tab, Enter)로 사용할 수 있습니다. Esc로 열린 창을 닫습니다.

## 현재 구현

2026-10-06 의상 확장: 미니스커트 4종과 팬츠·미디 코디 4종을 추가해 **의상 총 14종**. 상점의 상품 이미지에서 전신을 미리 보고 구매·착용할 수 있습니다. [패션 조사·이미지·검증 기록](docs/FASHION_COLLECTION_2026-10-06.md).

- **관계와 이야기 35편**: 기존 관계 이야기 10편을 친구·입사 전 설정으로 수정하고, 6개 테마의 후속 이야기 24편과 과거편 마지막 이야기 1편을 추가했습니다.
- **선택형 데이트 51코스**: 기존 3곳 + 물길·책과 그림·식탁·공방·음악·도시의 48개 탐방 코스. 새 코스는 6장면, 서로 다른 방문 경험으로 다음 코스와 이야기를 엽니다.
- **데이트 체험 3종**: 산책길 탐색, 음의 조각 퍼즐, 추억 카드. 48코스 × 12단계 = **576개 생성형 체험판**. 새 대본 576편이라는 뜻은 아닙니다. 힌트·되돌리기·재시도·중간 저장을 지원하며, 체험은 결말을 막지 않는 선택 활동입니다.
- **탐방 수첩**: 48곳의 첫 대화·코디와 체험 완성 기록을 영구 보관합니다. 검색·테마·미방문·방문 완료·출발 가능 필터와 페이지 탐색을 제공합니다.
- **한글 폰트**: 제목·대사는 고운바탕, 메뉴는 Pretendard. 공식 OFL 폰트와 라이선스를 게임 폴더에 포함해 오프라인에서도 표시됩니다.
- **대화 중 저장·재개**: 비용은 출발 시 한 번 차감. 중간에 닫거나 다시 접속해도 이어 읽기. 앨범과 지난 이야기 다시 읽기는 진행을 바꾸지 않습니다.
- 기본 관계 결말은 기본 후드와 무료 산책으로 진행할 수 있습니다. 탐방 마지막 이야기는 48개 코스와 후속 이야기를 마쳐야 열립니다.
- **30시간 이상은 설계 목표이며 실측 완료가 아닙니다.** 체험 숙련도와 힌트 사용에 따라 시간이 크게 달라집니다. 텍스트만으로 30시간을 제공하는 버전은 아닙니다.
- 아래 이전 검토 보고서는 작성 당시의 구현 상태입니다. 최신 상태는 위 구현 보고서를 따릅니다.

## 저장 주의사항

저장은 현재 브라우저의 `localStorage`에 남습니다. 시크릿 모드, 브라우저 데이터 삭제, 다른 브라우저·파일 경로로 이동하면 자동으로 이어지지 않을 수 있습니다. **저장 → 파일 내보내기**로 백업하면 다른 실행 환경에서 가져올 수 있습니다. 파일은 로컬에서만 처리하며 외부 서버로 전송하지 않습니다.

자동 저장이 막힌 동안에는 **현재 창 안의 진행을 유지**하며 상단에 파일 백업 버튼을 표시합니다. 타이틀로 돌아가도 현재 세션으로 이어할 수 있지만, 창을 닫거나 새로고침하면 미저장 진행을 잃을 수 있으므로 먼저 파일로 보관해 주세요. 저장이 다시 가능해지면 다음 저장 시 최신 세션을 기록하고 안내가 사라집니다.
