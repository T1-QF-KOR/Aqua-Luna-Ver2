# Aqua Luna · 수련과 보내는 하루

수련을 중심으로 하는 **텍스트형 연애 시뮬레이션 시스템 프로토타입**입니다. 스토리·시나리오·대사·엔딩은 사용자와 논의하여 별도로 계획합니다.

## 실행

`index.html`을 Chrome 또는 Edge에서 열면 됩니다. 설치, 빌드, 인터넷 연결이 필요하지 않습니다. 모든 버튼은 마우스·터치·키보드(Tab, Enter)로 사용할 수 있습니다. Esc로 열린 창을 닫습니다.

## 현재 구현

- 주인공의 일하기 3종: 수입 지급, 시간·기력 차감
- 날짜, 하루 시간 3칸, 휴식, 다음 날 회복
- 데이트 3종: 무료 산책 / 유료 카페 / 신뢰 조건이 있는 공연
- 의상 3종: 구매, 영구 보유, 무료 착용 변경. **착용 상태는 텍스트로 표시**하며, 기본 사복 일러스트는 참고용입니다.
- 호감·신뢰 수치, 하루 데이트 횟수 제한
- 소지금, 누적 수입·지출, 최근 200건의 활동 기록
- 의상·데이트 저축 목표, 부족 금액·예산 준비 상태, 활동 전후 자원 미리보기
- 자동 저장, 수동 저장 3칸, JSON 저장 파일 내보내기·가져오기
- 본문 글자 크기 3단계, 보조 일러스트 끄기, 움직임 줄이기, 선택적 합성 배경음
- PC·모바일 반응형 화면

직업·활동 종류와 모든 밸런스 수치는 임시입니다. 상세 경계는 [시스템 설계](docs/SYSTEM_DESIGN.md)를 참고하세요. 스토리와 능력치 변화에 따른 확정 대사·연애 사건은 구현하지 않았습니다.

## 파일 구조

| 파일 | 역할 |
| --- | --- |
| `src/data.js` | 직업·데이트·의상 데이터와 밸런스 |
| `src/engine.js` | 화면과 독립된 경제·행동 규칙, 저장 검증 |
| `src/app.js` | 텍스트 UI, 확인창, 저장·오디오 |
| `src/style.css` | 반응형 스타일 |
| `src/reading.css` | 읽기 설정, 예산 계획·자원 비교 화면 |
| `assets/` | 로컬 보조 일러스트 |
| `tests/runner.html` | 엔진 테스트. 브라우저에서 직접 열 수 있음 |
| `tests/ui.html` | 자동 클릭 및 화면 검증용 페이지 |

텍스트와 선택지 중심이며 실시간 물리·맵 이동이 없어 HTML DOM과 독립 JavaScript 상태 모듈을 사용했습니다. 프레임워크·CDN·패키지 의존성이 없습니다.

## 저장 주의사항

저장은 현재 브라우저의 `localStorage`에 남습니다. 시크릿 모드, 브라우저 데이터 삭제, 다른 브라우저·파일 경로로 이동하면 자동으로 이어지지 않을 수 있습니다. **저장 → 파일 내보내기**로 백업하면 다른 실행 환경에서 가져올 수 있습니다. 파일은 로컬에서만 처리하며 외부 서버로 전송하지 않습니다.

## 검증

`tests/runner.html`에서 경제 규칙 테스트를 실행할 수 있습니다. 상세 결과와 실행 방식은 [검증 기록](qa/REPORT.md)을 참고하세요.

원본 `../Aqua-Luna` 폴더는 수정하지 않았습니다. 설정 출처와 생성 이미지 프롬프트는 [출처 기록](docs/SOURCES.md)에 정리했습니다.
