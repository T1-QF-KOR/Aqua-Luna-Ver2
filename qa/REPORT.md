# 검증 기록

검증일: 2026-10-04 (사용자 시간대 Asia/Seoul).

## 통과

- 엔진 테스트 **17/17 통과**: 기본 상태, 일하기, 시간·기력 제한, 의상 구매·보유·착용, 중복 구매 방지, 잔액 부족 시 무변경, 데이트 비용과 1일 제한, 신뢰 해금, 회복, 관계 상한, 저장 검증·손상 복구, 저축 목표 유지·완료, 예산/신뢰 조건 구분, 이전 저장 호환, 실제 증가량 표시.
- 위 테스트에는 고정 시드 **3,000회 행동 시퀀스**가 포함됩니다. 매 단계 `소지금 = 초기 자금 + 누적 수입 − 누적 지출`, 정수 범위와 보유 상태, 실패한 행동의 무변경을 확인했습니다.
- Chrome 실제 DOM 클릭 검증: 새 게임 → 영상 편집 외주 → 니트 구매 → 착용 → 유료 카페 → 일일 데이트 제한 → 수동 저장 → 다음 날 → 불러오기 → 가계 기록 → 그림 표시 설정 → 타이틀 → 이어하기.
- PC 실제 콘텐츠 폭 **1424px**, 모바일 프레임 **390px**에서 위 UI 흐름 통과. 가로 넘침 없음, 핵심 버튼 너비 44px 이상/높이 36px 이상, 실행 중 JavaScript 오류 없음.
- 생성 캐릭터 이미지 알파 채널 확인: `Format32bppArgb`, 모서리와 외곽 알파 0.
- 시작 화면, 활동 화면, 모바일 화면을 이미지로 열어 직접 검토했습니다.
- 추가 UI 검증: 니트 저축 목표 → 부족 금액 40,000원 표시 → 일하기 전 잔액 155,000원 미리보기 → 취소 시 무변경 → 일하기 후 예산 준비 → 해당 의상 구매로 목표 완료. 본문 21px 설정의 즉시 적용·환경 저장 및 활동 패널과 하단 요약의 겹침 없음도 확인했습니다.
- 최신 캡처: `desktop-reading.png`(21px 활동 본문), `budget-mobile.png`(390px 예산 창). 두 파일 모두 열어 확인했으며 긴 예산 창은 내부 스크롤로 제공합니다. 기존 `desktop.png`, `mobile.png`, `title.png`는 v0.1 시점의 참고 캡처입니다.

## 검증 방법

`tests/runner.html`: 브라우저에서 직접 열어 실행. 결과는 페이지에 표시됩니다.

`tests/ui.html`: 별도 테스트용 Chrome 프로필에서 실행했습니다. file URL의 프레임 접근을 위해 테스트 브라우저에만 `--allow-file-access-from-files` 옵션을 사용했습니다. 실제 게임 실행에는 이 옵션이 필요하지 않습니다.

모바일 Headless Chrome의 기본 최소 레이아웃 폭이 500px로 잡혀, `tests/ui.html?viewport=390`으로 내부 프레임을 정확히 390px로 고정했습니다. 캡처 크기만으로 모바일 검증을 주장하지 않았습니다.

테스트 프로필·브라우저 로그는 `.gitignore`로 제외합니다. 샌드박스 내부 Chrome은 GPU 프로세스 초기화에 실패했으며, 승인된 프로젝트 전용 테스트 프로필로 실행해 검증했습니다. 사용자의 기존 브라우저 프로필은 사용하지 않았습니다.

## 범위와 제한

- Chrome/Windows에서 검증. 실제 모바일 기기, Safari, Firefox는 미검증.
- 실제 음향 청취 검증 및 스크린리더 낭독 검증은 수행하지 않음.
- 경제 밸런스는 임시이며 장기 플레이 재미·최적 행동 전략은 사용자와 후속 조정 필요.
- 시나리오, 대사, 고백, 엔딩은 의도적으로 미포함. 스토리 검증을 완료한 게임이 아니라 **경제·행동 시스템 프로토타입**.
- 옷은 텍스트 이름·설명·보유 상태로 변경. 일러스트의 복장이 변하는 기능은 없음.
