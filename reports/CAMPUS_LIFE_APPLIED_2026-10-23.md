# 통학·학식·알바·데이트 선택 적용 보고서

2026-10-23 · 사용자 지시: “통학 학식 알바 데이트 이것들만 적용시키고 그에 맞게 시나리오 스토리도 바꿔”, “대사도 같이 바꿔”. 이 두 지시를 네 생활 요소와 관련 실행 대사의 적용 승인으로 처리했다.

## 적용한 내용

| 항목 | 적용 전 | 적용 후 |
| --- | --- | --- |
| 통학 | 이동·귀가가 주로 생략됨 | 두 사람은 각자 집에서 통학. 수업·왕복 통학 뒤 자유 시간을 기존 3칸으로 표현. 산책의 돌아올 지점, 공연 뒤 환승, 귀가 후 연락을 대사에 반영 |
| 학식 | 별도 기본 코스 없음 | `lunch` 공강 사이 학식 3장면. 평일 첫 활동, 식권 1인 5,000원 × 2장 = 10,000원. 내가 두 장을 결제하며 하루 데이트 1회에 포함 |
| 카페 알바 | 아무 요일에 같은 근무 반복 가능 | 수·금·토 4시간, 45,000원. 다른 일감을 포함해 근무·납품 하루 1회 |
| 영상 외주 | 즉시 반복 수입 | 사전에 맡은 짧은 영상 한 편의 수정·납품. 75,000원 유지, 하루 1건, 다른 근무와 같은 날 중복 불가 |
| 행사 보조 | 아무 요일에 가능 | 토·일 8시간, 120,000원. 긴 현장 근무일에는 외출 제한 |
| 일상 데이트 | 카페 35,000원 | 음료 두 잔 12,000원, 무료 산책 유지. 학식·카페는 짧은 만남, 공연은 미리 비운 날의 특별 외출 |
| 공연 일정 | 근무 직후에도 출발 가능 | 공연과 근무는 같은 날 중복 불가. 근무 후 공연·공연 후 근무 양쪽 모두 제한 |
| 대본 | 추상적인 감정 질문 중심 | 수업·학식 메뉴·가방·과제·교대·귀가를 구체적인 대화 소재로 사용. 짧게 만나도 다음 만남이 자연스럽게 이어지는 흐름 |

금액과 근무 요일은 이 게임의 가상 학교·가게 설정이다. 실제 학교 전체의 평균 가격·실제 채용 조건으로 제시하지 않는다. 즉시 정산은 플레이 편의 규칙이다. 통학은 기본 생활 시간과 서사에 반영했으며 노선 검색·실시간 막차·교통비 자동 결제 기능은 만들지 않았다. 학교의 정확한 지리와 집안 사정도 추가로 확정하지 않았다.

## 시나리오 흐름

`수업 후 만남 → 공강 사이 학식 → 각자 과제·근무 → 근무 없는 날 짧은 카페·산책 → 미리 예매한 공연 → 귀가 확인과 다음 약속`

도입부 후반 2장면, 주요 사건 `hello / space / invite / epilogue` 4편, 기본 데이트 3종의 9장면을 수정했다. 학식 3장면을 추가하고 근무 안부 6종, 카페 후속 메시지, 학식 다음 날 메시지와 답장을 작성했다. 총 데이트는 **52코스(기본 4 + 탐방 48)**, 주요·후속 이야기는 기존 **42편**이다. 새 NPC나 사건 개방 조건은 추가하지 않았다.

## 대사 전 / 후

| 장면 | 전 | 후 |
| --- | --- | --- |
| 첫 연습실 약속 | “좋아요. 끝나는 시간도 같이 적어요.” | “좋아요. 돌아갈 시간부터 적어 둬요. 둘 다 내일 아침 수업 있잖아요.” |
| 카페의 대화 | “좋아하는 일을 계속하면… 늘 행복해야 하는 걸까요?” | “수업 끝나면 알바 가고, 쉬는 날에는 밀린 과제 하고. 이번 주는 시간이 되게 빨리 가네요.” |
| 카페의 속마음 | “저만 그런 건 아니었네요.” | “길게 못 만나면 다음으로 미뤄야 하나 했는데… 이렇게 잠깐 보는 것도 괜찮네요.” |
| 산책의 시작 | “오늘은 멀리 가지 않아도 괜찮아요. 어디부터 걸을까요?” | “오늘은 저 다리까지만 갔다 와요. 환승 놓치면 내일 아침에 후회할 것 같아서요.” |
| 후일담의 다음 약속 | “다음번에는 제가 코스를 골라도 돼요? 늘 걷던 길에서, 조금만 돌아가 봐요.” | “다음번에는 제가 점심 살게요. 학식 먹고 정류장까지 같이 가요. 멀리 안 가도 좋겠어요.” |
| 학식, 새 장면 | 없음 | “오늘은 수업 끝나면 바로 집 가요? 아니면 알바 있어요?” → “저는 연습 조금만 하고 가려고요. 집 가는 데도 시간이 걸리니까, 너무 늦게까지는 말고요.” |

감정 표현은 일상 상황에서 나오도록 바꿨다. 카페에서 짧은 약속을 잡느라 애쓴 것을 알아주거나, 학식의 다음 공강을 묻거나, 귀가할 때 뛰지 않도록 돌아설 시점을 정하는 선택이 관계 변화로 이어진다.

## 조사 근거와 구현의 구분

이전 [현실성 조사 보고서](proposals/2026-10-23/UNIVERSITY_REALISM_REPORT.md)의 자료를 사용했다. 식비는 [포항공대신문의 특정 학교 학식 사례](https://times.postech.ac.kr/news/articleView.html?idxno=23931), 공강에 맞춘 근무는 [서울교대 단기 근무 모집 사례](https://www.snue.ac.kr/snue/na/ntt/selectNttInfo.do?bbsId=1081&mi=1280&nttSn=53400)를 참고했다. 이를 가상 학교의 가격과 요일로 설계했으며 그대로 일반화하지 않았다. 연애 작품의 구체적 대사나 장면을 복제하지 않았다.

## 검증과 한계

- 변경 전 핵심 로직 **104/104**, 변경 후 새 생활 검사를 포함한 **114/114 통과**. 장기 관계 진행, 금전 불변식, 분기·저장, 일정 일괄 실행, 신규 코스, 자산 경로를 검사했다. 등록 에셋 80개 누락 없음.
- 새 생활 검사 10개: 2주치 근무 요일, 하루 근무 상한, 기록 잘림 뒤 상한 유지, 이전 저장의 근무 추론, 학식 중간 저장·단일 결제, 주말/늦은 점심 제한, 식사 메시지·반말 분기, 긴 일정 충돌, 예약 무효화, 기존 선택 ID 유지.
- 실제 브라우저 1280×720에서 새 게임 → 월요일 근무 제한 → 학식 초대/준비 → 3장면 선택 → 완료/추억 기록 → 잔액 70,000원·시간 2칸 → 귀가 후 다음 날 전환을 확인했다. 브라우저의 오류·경고 로그 없음.
- 학생식당은 새 배경 제작 없이 기존 낮 카페 이미지를 임시 재사용한다. 장소 이름·대사·진행은 학생식당으로 구분했다.
- Windows EXE의 네이티브 실행/재패키징은 이번 macOS 작업에서 검증하지 않았다. 변경은 소스 실행본에 반영했다.
