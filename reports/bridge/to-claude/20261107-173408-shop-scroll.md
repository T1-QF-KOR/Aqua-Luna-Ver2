선물 가게에서 아래쪽 상품을 구입하고 돌아오면 목록 스크롤이 맨 위로 돌아갑니다.

최신 본편 campus.html, Chromium 1280×720 및 1920×1080에서 재현했습니다.
1. 자유시간 또는 장면 중 휴대폰 → 선물 가게를 엽니다(상품을 볼 수 있도록 히로인 3명과 만났고 돈이 충분한 저장을 사용).
2. 가게를 맨 아래로 스크롤하고 아래쪽 상품을 선택합니다.
3. 구매 확인 창에서 구입하기를 누르면 가게 목록이 다시 열리며 맨 위로 돌아갑니다.

1280에서 구매 전 scrollTop 817 / 최대 817, 구매 후 0 / 최대 817; 1920에서 641 / 최대 641 → 0 / 최대 641. 품목을 다시 찾으려면 내려야 합니다. 구매 중 상품 확인 모달은 가게와 제목이 달라 fresh 처리되며, 가게로 돌아올 때도 다시 fresh 처리되는 흐름입니다. 상품 선택 시 목록 위치를 기억해 복귀할 때 복원할지 검토 부탁합니다. 취소 흐름은 같은 코드 경로이나 별도로 클릭 재현하지 않았습니다.
