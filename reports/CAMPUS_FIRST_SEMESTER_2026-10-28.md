# Aqua Luna · 1학기 구현과 검증

기록일: 2026-10-28 (Asia/Seoul). 전체 목표는 고품질 미연시 완성이다. 이 문서는 현재 개발 증거이며 완성 선언이 아니다.

후속 변경: [선물·데이트·앨범·기본 질투 구현](CAMPUS_RELATIONSHIP_ACTIVITIES_2026-10-28.md). 아래 검증 수치와 남은 작업은 1학기 전환 당시 기록이며 최신 관계 활동은 후속 문서를 따른다.

## 기준과 진입점

- 사용자가 지정한 새 GDD(한여울대 · 한나리 · 오다은 · 백서진)를 따른다. 기존 게임은 UI 완성도의 최소 기준이며, 이전 기능·설정·저장을 보존해야 한다는 요구는 없다.
- 인물 미술 방향은 사실적인 표현에서 **애니메이션 셀 채색과 버추얼 캐릭터 느낌**으로 변경한 사용자 지시를 따른다. 이전 사실적 시안은 현재 빌드에 쓰지 않는다.
- `index.html`이 새 기획의 기본 실행본이다. `campus.html`도 같은 HTML과 소스를 사용한다. 일치 여부는 실행 자원 검사에 포함된다.
- 현재 플레이 가능한 시간은 **2026년 3월 2일~6월 30일**이다. 6월 말 안내는 개발 구간의 경계이며 게임 결말이나 목표 달성으로 처리하지 않는다.

### 이야기

- 공통: 날짜·입학 독백 인트로, 서울의 첫날, 축하 무대, 새내기 배움터, 동아리 박람회(나리 미대면 시 실제 첫 만남 대체), 첫 방송, 봄 대동제의 3갈래 선택.
- 나리: 강의실·옥상·강변 첫 만남 3종 중 먼저 방문한 곳, 떨리는 손, 마이크를 끄고, 같은 말버릇, 첫 줄에서 막힌 가사, 삭제하지 않은 파일.
- 다은: 1순위 떡볶이, 사진 바깥의 사람, 자전거로 끝까지, 읽고 답 없는 단톡방.
- 서진: 첫 출근, 마감 플레이리스트, 손잡이의 방향, 우산은 하나.
- 교차: 드러머 오디션, 목요일의 합주, 비 오는 카페의 셋. 수요일 노을에 실제로 나리가 함께 있을 때만 세 번째 인물과 보상을 포함한다.
- 봄 대동제를 마무리해도 보지 않은 다른 히로인의 사건이나 보상을 자동 부여하지 않는다.
- 사연의 작성자를 알아보는 문장과 현실에 꺼내는 선택지는 실제로 들었거나 당사자에게 알게 된 조건에 따른다.

### 코드의 경계

- `world.js`: 달력·일정·관계 배율·상한. 실제 날짜나 OS 시간대를 게임 날짜로 쓰지 않는다.
- `radio.js`: 방송 편성·사연 문장·낭독과 청취·재방송·단서. 이후 회차의 편성 데이터와 기본 방송 멘트는 있으나, 이후 루트와 결말의 구현 완료를 의미하지 않는다.
- `state.js`: 새 세션과 저장 검증·이전 캠퍼스 빌드 상태 복원.
- `scenes.js` / `semester.js`: GDD를 바탕으로 구성한 대사·선택·조건.
- `game.js`: 실제 플레이 화면, 입력, 장면 진행, 장소·휴대폰·설정·저장 처리.

## 검증 증거

| 검사 | 결과 | 실제로 보장하는 범위 |
|---|---|---|
| `node tests/campus-v2.test.mjs` | **15/15 통과** | 학사력, 30회 날짜, 숨은 위치 비노출, 배율·상한, 발송/낭독/청취·재방송, 조건부 지식, 이야기 조건, 저장 상태 |
| `node tests/campus-v2-runtime.test.mjs` | **10/10 통과** | 실제 `game.js` 입력 처리와 DOM 어댑터. 인트로 시작·재개·건너뛰기·타이머·메뉴/백그라운드 정지·움직임 줄이기, 사연 전이, 저장 중 정산, 대화, 축제 분기, 취소·수동 복원, 세 사람의 근무, 개발 경계 |
| `node tests/campus-v2-assets.test.mjs` | **23개 자원 통과** | 두 진입점의 일치, 스크립트 의존 순서, 배경·입상·폰트·아이콘의 실제 파일, 배포 대상 폴더 |
| 입상 파일 검사 | **3개 확인** | 1024×1536 RGBA, 투명 영역과 실질 불투명 영역 존재. 표정·Live2D 동작 완료 검증은 아님 |
| Safari 실제 화면 | 일부 경로 확인 | 타이틀·이전 캠퍼스 체크포인트 이어하기·밤 화면·달력·휴대폰·6화제 선택·대화 후 원래 장소 복귀와 하루 1회 제한. 스크린샷을 대화의 도구 결과로 검토 |

인트로 추가 후 Safari에서 새 게임 → 이름 입력 → 날짜와 입학 독백 → 두 번째 페이지 자동 전환 → 원래 자취방 프롤로그 진입을 확인했다. 첫 페이지와 본편의 실제 스크린샷을 검토했고, 표시된 날짜와 소지금·기력이 그대로 이어졌다. 인트로를 건너뛰어도 지난 시즌 방송을 듣는 본편 선택은 생략하지 않는 것을 런타임 검사에서 확인했다.

검사 결과 파일은 `qa/campus-v2/`에 있다. `runtime-results.json`은 실제 게임 코드를 실행하지만 **실제 브라우저 렌더링 검사가 아니다**. 화면 검증은 별도로 구분한다.

Safari의 네이티브 파일 선택 창에서 컴퓨터 제어 응답이 멈췄고, 재확인 시 입력 대상이 사용자의 조작으로 바뀌었다. 해당 경로의 검증을 중단했다. 따라서 **새 파일 가져오기의 네이티브 파일 선택부터 복원까지는 이번 턴에 완료 확인하지 못했다.** 코드와 저장 상태 검사는 통과했지만 이를 실제 파일 선택 검증으로 대체하지 않는다.

## 데스크톱 연결

- Windows 실행기 제목을 새 기획에 맞추고 자동 저장 실패 경고의 DOM 연결을 갱신했다.
- 개발 경로 탐색을 새 코드 위치로 바꿨다.
- 패키징 스크립트는 새 런타임 폴더와 사용 중인 아트·폰트·UI 폴더만 복사한다. `assets/미사용`과 예전 인물 제작 소스를 포함하지 않는다.
- **이번 턴에는 Windows EXE 빌드·실행·다운로드 창·종료 경고를 검증하지 않았다.** 기존 Windows 검증 결과는 새 게임의 검증 결과로 재사용하지 않는다.

## 전체 목표에 남은 작업

1. 여름·가을·겨울의 루트 장면과 실제 조건·공유 이력을 연결하고, 고백·거절·보류·화해·등록 마감까지 구현.
2. 단독 연애와 공개 합의형 여러 연인, 질투·목격·소문·수라장·발렌타인 및 14종 결말. 현재 전부 완료된 상태가 아님.
3. 선물·데이트·메시지·앨범과 각 인물의 선택 결과가 장기 관계에 돌아오는 흐름.
4. 추가 표정·의상·무대 입상·전용 CG, 모든 장소의 애니풍 배경 일치. 현재 기본 입상 1종씩이며 Live2D 리깅은 없음.
5. 완성도 있는 BGM·핵심 멜로디 복선·방송 음향·보이스. 현재 짧은 선택 효과음만 제공.
6. PC 최소/권장 해상도 전수 화면 검사, 실제 처음부터 각 결말까지 반복 플레이, 저장 파일의 실제 이동과 실패 상황, 성능과 접근성, Windows 새 패키지와 Steam 출시 검증.

다음 우선순위는 여름 루트와 관계 활동이다. 1학기 확장을 전체 목표의 축소나 완성으로 취급하지 않는다.
