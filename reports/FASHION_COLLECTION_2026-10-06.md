## 상점과 게임 연결

- 신규 코디를 상품 목록 앞에 배치. 전체 / 새 코디 / 미니스커트 / 미디·롱 / 팬츠 코디 / 소품 필터.
- 각 상품에 수련이 실제로 입은 PNG, 이름, 구성, 가격, 보유 여부·부족 금액 표시.
- 그림을 누르면 무료 전신 미리보기. 현재 코디·돈·시간은 바뀌지 않으며 돌아와도 필터 유지.
- 구매 확인 후 보유 목록에 추가하고, 옷장에서 직접 입힐 때 메인 캐릭터도 해당 PNG로 변경.
- 신규 8종은 전신 그림이므로 메인 화면에서도 전신 의상 배치를 적용.
- 데이트 준비·대화에서도 동일한 코디 유지. 이후 갈아입어도 앨범은 그날의 PNG와 선택을 보존.
- 상점 이미지는 옷이 잘 보이는 밝은 CSS 배경 위에 투명 캐릭터를 표시. 데이트와 앨범은 기존 장소 배경 사용.
- 모든 파일은 프로젝트 내부에 포함되어 네트워크 연결 없이 실행 가능.

## 제작 기록

내장 **image_gen** 도구로 의상마다 한 번씩, 총 8회 생성했다. 참조는 기존 `assets/characters/skirt.png`. 얼굴·머리·눈·헤드폰·자세와 채색 스타일을 유지하고 의상만 바꾸도록 요청했다. 새 의상마다 1024×1536 RGBA PNG를 프로젝트의 `assets/characters/`로 복사했으며 기존 이미지와 생성 원본은 보존했다.

정확한 공통 프롬프트+각 코디 프롬프트, 참조 경로, 생성 원본 경로는 [fashion-image-prompts.json](../docs/fashion-image-prompts.json)에 있다. 배경 투명도 요청은 `transparent_background: true`. 파일 크기·SHA-256·해상도·모서리 alpha 검사 결과는 [에셋 검사](../qa/fashion-asset-audit.json)에 있다. 신규 8장 합계 11,960,097바이트이며 별도 손실 압축은 하지 않았다.

## 검증

- 새 의상 검사: PC 1440px / 모바일 390px 각각 **13/13 통과**. 8종 모두 실제 화면에서 돈 벌기→구매→직접 착용→무료 데이트→대화 완료→앨범→저장 복원 확인.
- 상점 분류별 수량, 잔액 부족·중복 구매 방지, 무료 미리보기 무변경, 돌아가기 필터 보존, 전신 배치, 표정 대체 시 옷 유지 확인.
- PNG 8장 각각 1024×1536, 서로 다른 SHA-256, 네 모서리 alpha=0, 브라우저 디코딩 통과. 기존 포함 **42개 이미지 로딩** 통과.
- 기존 경제·저장 장애·스토리·옷장·키보드 검사까지 이번 실행에서 **총 119건 통과**.
- PC/모바일 상점과 확대 미리보기 스크린샷을 직접 검토. 21px 본문 설정에서 가로 넘침·버튼 크기도 확인. 실제 모바일 기기·Safari·Firefox는 이번 검사 범위 밖.
