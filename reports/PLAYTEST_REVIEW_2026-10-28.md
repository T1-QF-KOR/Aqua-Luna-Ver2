## 4. 참고작과 비교

참고작은 [스팀 미연시 조사](../GDD/스팀_미연시_제작자료/01_스팀게임별_분석.md)의 8편이다. 왼쪽은 공식 상점 소개로 확인한 특징이다. 참고작을 직접 플레이하지는 않았다.

| 참고작 · 확인한 특징 | Aqua Luna 지금 | 부족한 점 |
|---|---|---|
| **러브 딜리버리** — 카페 알바·자기 계발·상대와의 시간을 나누고, 그 결과로 이야기가 달라짐 | 알바·공부가 숫자만 올림. 장면 없음 | 일과 성장에 **목적과 장면**이 없다. 돈·능력치를 쓸 곳이 없다 |
| **썸썸 편의점** — 앱(휴대폰)을 계기로 관계가 이어짐, 일터에서 반복 만남 | 휴대폰은 메뉴 모음. 메시지 없음 | GDD/06 §5 **메시지(썼다 지우기)**와 §6 **민재 귀띔**이 미구현 |
| **Love Esquire** — 능력치가 여러 상황의 대화·관계에 영향 | 능력치 사용처는 「지식 15」 선택지 1곳 | 능력치에 따라 달라지는 대사·선택지가 거의 없다 |
| **Love on Leave** — 상대가 없어도 할 일(탐색·수집·부탁), 발견물을 선물·부탁에 씀 | 혼자 활동은 알림 한 줄(“달리기 · 체력 +3”) | 혼자 보내는 시간에 **소사건·발견·부탁**이 없다 |
| **Hush Hush** — 일정 관리로 하루 선택에 긴장 | 히로인이 매주 같은 자리. 놓칠 일이 거의 없음 | 최신 코드가 무작위 위치·날씨를 넣는 중. 놓친 일을 알려 주는 장치가 필요 |
| **러브인 로그인** — 공통 관심사 + 미니게임 | 작곡 = 드롭다운 2개, 결과는 같은 문장이 쌓임 | 음악 게임인데 **음악을 만드는 손맛**이 없다 |
| **Love Too Easily** — 놀이 결과를 뒤에서 다시 씀, 일지, 2회차 건너뛰기 | 카드 4장, 쓰는 곳 없음. 읽은 대사 건너뛰기 없음 | 회차 플레이용 **기읽음 건너뛰기**와 카드 사용처 |
| **Dream Daddy** — 데이트마다 다른 미니게임, 사이드 퀘스트 | 데이트 5줄 + 선택 1개. 부탁 없음 | 데이트 체험과 조연 부탁(GDD/14 Q01~Q05) |
| 공통 — 성우·CG 강조(러브 딜리버리·썸썸 편의점·Love Esquire·러브인 로그인) | 표정 0, CG 0, 배경 음악 0 | 감정 장면을 보여 줄 수단이 없다 |

**잘하고 있는 점(유지):** 타이틀·인트로·배경의 완성도, 대사 문장의 질(특히 나리 「같은 말버릇」, 서진 「손잡이의 방향」), 라디오가 현실 단서와 겹치는 구조, 읽기 설정·자동 저장·달력, 「실제로 들은 것만 안다」는 규칙.
