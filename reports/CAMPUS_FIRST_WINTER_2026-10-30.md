# 고백 이후의 하루 · 2026-10-30

현재 개발 빌드를 12월 20일까지 연결했다. 이번 작업은 고백 장면을 보여 주는 것에 더해, 대답이 실제 관계 상태와 이후 장면을 바꾸게 하는 데 집중했다. 도중에 사용자가 지정한 나리 의상 두 벌의 재디자인도 완료했다.

## 이야기와 관계 상태

`winter.js`에 장면 11편을 추가했다. **나간 사람 / 녹음실의 새벽 / 두 장의 종이 / 첫눈 / 종강 파티가 끝나고 / 시간표의 마지막 칸 / 마감이 아닌 약속 / 그다음 마감 / 기다린다는 말 / 공지 없는 약속 / 단톡방에서, 내일도**다. 그 밖에 보호된 11월 19일 방송과 관계 합의·합의 재검토·숨긴 관계의 충돌 장면을 동적으로 구성한다.

- 서진은 11월 25일, 다은은 12월 18일에 조건에 맞으면 고백한다. 상대를 실제로 만났어야 하며, 연인이 없으면 마음 55, 이미 있으면 70이 필요하다. 고백을 앞서 본 사람이나 친구로 대답한 사람에게 같은 고백을 반복하지 않는다.
- **연인 / 친구로 대답한 사이 / 대답을 기다리는 사이 / 함께 이야기하기로 한 사이**를 호감도와 별도로 저장한다. 높은 호감도만으로 연인이 되지 않는다. 보류하면 다음 날부터 14일간 긍정적 반복 행동의 효과가 절반이 된다.
- 두 번째 마음을 공개하고 이야기하기로 했을 때 새 관계는 아직 확정하지 않는다. 다음 날 함께 대화하며 기존 연인의 마음·서운함·이전 충돌에 따라 합의, 조건부 합의, 거절로 나뉜다. 거절이면 실제로 한 사람에게 대답해야 한다.
- 조건부 합의는 기존 연인과 두 주 동안 두 번씩 완료한 데이트를 센다. 중복 정산이나 같은 저장을 다시 읽는 것으로 횟수가 늘지 않는다. 조건을 채워도 재검토 장면에서 동의를 다시 확인해야 한다. 기한이 지나 조건을 못 채웠으면 자동 승인하지 않는다.
- 숨긴 교제는 관계 노트에서 털어놓을 약속을 잡을 수 있다. 다른 연인이 실제 데이트를 목격한 경우에는 그날 밤 충돌 장면을 연다. 정직한 대답·한 사람 선택·얼버무림이 각각 다른 기록과 관계 손실을 남긴다. 충돌을 한 번 해결했다고 곧바로 다자 교제에 동의한 것으로 보지 않는다.
- 연인은 7일, 연인이 아닌 사이는 14일의 멀어짐 기준을 사용한다. 공개 합의한 연인 사이의 질투 감점은 절반이다. 만남의 인사와 관계 노트에도 실제 대답 상태를 반영한다.

서진의 강사 합격은 실제로 지원서를 제출한 기록이 있을 때만 고백 대사에 나온다. 지원하지 않았으면 별도의 대사로 진행한다. 교제를 받아들인 뒤와 친구·보류로 대답한 뒤에는 서로 다른 자유 사건이 열린다. 다은의 갈등 장면도 실제로 답하지 않은 메시지가 있을 때만 그 일을 언급한다.

11월 19일 아침에는 녹음실로 가는 나리와 만날 수 있다. 이 장면은 평일 아침 수업의 기력과 학습 기록을 한 번만 처리한다. 밤 방송은 휴방 보호 회차이며, 끝까지 듣거나 메시지·생방송 쪽지를 선택할 수 있다. 실제 방송 청취 기록으로 남고, 다시 듣기에는 선택과 보상을 반복하지 않는다. 실제 음성 연기나 4분 무음 연출을 제작한 것은 아니며 현재는 대사 중심 연출이다.

## 나리 의상 두 벌 재디자인

사용자가 지정한 두 벌은 상하의 실루엣과 옷 종류를 바꿨다. 내장 `image_gen`으로 해당 이미지를 각각 편집했으며, 얼굴·헤어스타일·분홍 메쉬·표정·장신구와 애니·버추얼 화풍을 유지했다.

| 이전 의상 | 현재 게임에 연결한 파일 | 상품·데이트 표기 |
|---|---|---|
| 카키 야상·카고 팬츠 | [nari-pinafore-v4.png](../archive/nari-previous-illustrations/nari-pinafore-v4.png) | 퍼프 블라우스 · 블랙 뷔스티에 원피스 |
| 큰 후드·와이드 팬츠 | [nari-cardigan-v4.png](../archive/nari-previous-illustrations/nari-cardigan-v4.png) | 크림 카디건 · 라벤더 톱 · 데님 스커트 |

둘 다 1024×1536 RGBA PNG다. 생성 결과를 직접 보고 확인했고, 바깥쪽 여러 지점의 투명도를 검사했다. 게임의 의상 카탈로그, 선물 가게 이름, 데이트 서술을 함께 갱신했다. 저장 중인 장면에 이전 상품명이 들어 있으면 새 그림과 맞게 읽어 온다. 내부 저장 키 `utility-cargo`, `casual`은 유지하되 그림은 v4 파일을 사용한다. 이전 v3 원본은 작업 기록으로 남아 있으며 현재 카탈로그에서 요청하지 않는다.

## 검증과 남은 범위

- 실제 `game.js`를 구동하는 런타임 검사 **37/37 통과**. 입학부터 12월 20일까지 **294일 진행**, 서진의 세 답변과 저장 복원, 다은의 두 번째 고백과 세 가지 합의 결과, 관계 노트의 공개 약속, 충돌 후 같은 밤으로 복귀, 보호 방송의 보상 중복 방지를 확인했다.
- 관계 모듈 검사 **9/9 통과**. 이전 저장의 이행, 불가능한 관계 상태 거부, 친구·보류, 명시적 합의, 실제 데이트 두 번과 기한 실패, 목격, 높은 재합의 기준, 연인 멀어짐과 인사를 확인했다.
- 겨울 자유 사건 **7편**은 실제 확률 일정에서 도달 가능하다. 고백 조건과 특별 방송 다시 듣기, 추가 정규 방송 6회의 대본도 확인했다.
- 핵심 25/25, 대화 8/8, 선물 의상 10종과 가을 사건 검사 통과. 자산 검사에서 두 진입점과 스크립트 순서, 참조 리소스 **72개**를 확인했다. `git diff --check` 통과.
- 새 일러스트는 생성 결과를 시각적으로 확인했다. Safari의 접근성 창을 한 차례 읽었으나 실제 입력을 시도하자 다시 `cgWindowNotFound`가 발생했다. 새 의상과 고백 장면의 최종 브라우저 배치·줄바꿈 검증은 남아 있다. DOM 어댑터 검사를 실제 브라우저 검증으로 표현하지 않는다.

12월 20일은 계속 개발 중인 구간의 체크포인트다. 12월 19일 시작한 조건부 합의의 두 주 전체는 아직 현재 빌드에서 플레이할 수 없다. 완료·실패의 처리와 저장은 날짜를 진행한 모듈 검사로 검증했으며, 성탄 이후 콘텐츠 연결이 더 필요하다. 나리의 성탄 고백, 성탄 초대와 교제 규칙 운영, 새해·겨울 후반·발렌타인·결말, 다 같이 보내는 시간과 장기 플레이의 재미 검증은 계속 남아 있다. 전체 게임이 완성됐다는 보고서가 아니다.
