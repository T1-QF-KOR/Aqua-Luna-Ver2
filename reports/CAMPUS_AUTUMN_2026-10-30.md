고정 전환 7편은 **추석, 어느 쪽의 집 / 괜찮다는 말 다음 / 돌아갈 때의 짐 / 다시 내 방 / 올해 루나는 누구? / 불 꺼진 복도 / 맨 앞줄과 맨 뒷줄**이다.

귀향하면 9월 24~26일의 낮 지도는 고향 방만 표시한다. 기존에 저장된 일정이 있어도 캠퍼스 만남을 막고, 금요일 급여를 받지 못한다. 목요일 방송은 고향에서 들을 수 있으며 27일 서울로 돌아온다. 서울에 남으면 기존 장소가 열린다.

익명 방송 소동은 촬영과 출구 제보를 다룬다. 이현은 자신이 지난 시즌 진행자였다고 밝히며 현재 부원의 신원을 보호한다. 정체를 모르는 플레이어에게 현재 진행자의 이름을 자동 확정하지 않는다. 목요일 밤에 들을 실제 방송과 오후의 준비·복도 장면을 구분했다.

축제에서는 실제로 한 앞줄·뒷줄·촬영 약속만 이행한다. 원래 가사 여부를 무대 대사에 반영하고, 만난 사람만 무대 뒤 선택지에 등장한다. 다은의 장비 철수 장면은 실제 밴드 가입이 필요하다. 혼자 남아 자신의 곡을 생각하는 선택도 있다.

놓친 기초 관계 사건 때문에 수치가 영구 정지하지 않도록 해당 사건과 서진 우산 사건의 선행 카페 사건을 학년 말까지 이어지게 했다. 자유 사건은 확률 일정과 실제 방문을 사용하며, 지도에는 인물이나 사건 표시를 추가하지 않았다.

## 배경 제작과 사용

내장 `image_gen`으로 기존 그림을 참조하여 제작했다. 원본을 덮어쓰지 않고 아래 파일로 저장했다. [최종 프롬프트·참조·생성 원본 기록](../docs/autumn-backgrounds-v1.json).

| 저장 파일 | 실제 사용 |
|---|---|
| [campus-summer-v1.png](../assets/campus-v2/campus-summer-v1.png) | 5월 15일~9월 30일 캠퍼스. 건물·강변 구도를 유지하고 벚꽃을 녹음으로 변경 |
| [campus-autumn-v1.png](../assets/campus-v2/campus-autumn-v1.png) | 10~11월 캠퍼스. 같은 구도의 단풍 |

여름 캠퍼스는 1671×941, 나머지는 1672×941 RGB PNG다. 네 그림을 시각적으로 확인했다. 인물이나 UI를 그림에 합성하지 않았다. 모든 야외 장소의 계절·날씨별 그림을 완성한 것은 아니며, 겨울 전용 캠퍼스는 남은 제작 범위다.

## 검증 결과

- `node tests/campus-v2-runtime.test.mjs`: **32/32 통과**. 실제 `game.js`를 구동하는 DOM 어댑터로 입학부터 242일 진행, 필수 장면 도달, 귀향·복귀·급여 제외, 방송 휴방 세 차례, 저장 후 중복 적용 방지, 계절과 고향 낮·밤 배경, 약속별 축제 선택을 확인했다. 모든 연애 루트를 실제 브라우저로 완주했다는 뜻은 아니다.
- `node tests/campus-v2-autumn.test.mjs`: 자유 사건 **12편 모두 실제 확률 일정에서 도달 가능**. 장면 19편의 조건부 선택과 대사, 모르는 사람 제외, 선행 관계 사건, 추가 방송 9회 확인.
- 핵심 규칙 25/25, 대화 8/8, 의상 10종 검증 통과. 확장 시스템 검사도 통과.
- 자산 검사: 두 진입점 일치, 스크립트 의존 순서, 리소스 **68개** 확인.
- 새 배경은 생성 결과를 직접 보고 검사했다. 브라우저 UI 제어는 Safari 재연결에서도 `cgWindowNotFound`가 발생했다. 신규 가을 장면의 실제 브라우저 화면 배치·줄바꿈·연출 검증은 남아 있다.

임시 저장만 사용하는 `qa/campus-v2/wardrobe-preview.html?scene=autumnFestival`로 축제 미리보기를 준비했다. `nariCard`, `nariFight`, `chuseokMorning`도 같은 `scene` 인자로 볼 수 있다. 실제 플레이어 저장은 읽거나 쓰지 않는다.
