# 관계 활동 구현 · 2026-10-28

전체 고품질 미연시 개발 목표를 진행 중이다. 현재 본편은 여전히 3월 2일~6월 30일이며, 이번 변경은 관계 활동을 추가한다.

## 실제 구현

- 휴대폰 선물 가게: GDD의 10종, 정확한 가격, 소지금, 보유 수량, 구입 확인·취소. 게임 시간을 쓰지 않는다.
- 실제 같은 장소에서 만난 인물에게 선물 전달: 재고 소모, 취향, 인물별 배율과 반복 행동 상한, 인물별 7일 간격. 생일 두 배와 알게 된 생일만 달력에 표시하는 처리도 연결했다. 생일 날짜는 현재 플레이 구간 이후이므로 규칙 검사로 검증했다.
- 만남 화면: 애니풍 인물 초상, 현재 관계 단계, 인사, 대화·선물·데이트의 비용과 이용 조건.
- 데이트: 한강변·카페·작은 공연·옥상·노래방, 오후와 노을 두 칸, 기력 15, 장소별 비용. 약속 확인 전에 자원을 쓰지 않으며 노을의 필수 사건과 충돌하면 차단한다.
- 인물·장소의 도입부 15종과 인물별 순환 대화 4종을 조합한다. 선택은 장면당 2개이며, 같은 상대·장소를 다시 찾으면 다음 대화로 돌아간다. 장소마다 완전히 독립적인 4편씩 총 60편의 장편 대본을 썼다는 뜻은 아니다.
- 앨범: 실제로 완료한 데이트만 날짜·장소·상대·선택한 말로 기록. 전용 사진 CG는 아직 없으며, 현재는 문장 카드 형식이다.
- 나리 노래방: 서로 다른 날의 첫 두 초대를 거절한다. 마음 45, 강변 정체 사건, 9월 이후 조건을 충족하면 「3번 방」으로 이어지는 데이터와 처리를 연결했다. **여름 루트가 아직 미구현이므로 현재 정상 플레이에서 이 특별 장면에 도달하지는 못한다.** 다른 14개 상대·장소 조합과 거절은 현재 구간에서 이용 가능하다.
- 기본 질투·목격: 실제 함께 있던 인물, 하루 한 번, 마음 35~54의 첫 자각과 이후 서운함, 55 이상의 감점. 나리는 현실에서 질투를 말하지 않고 다음 새 방송에 멘트가 남는다. 방송 기록에 고정해 다시 듣기가 새 감정을 만들지 않는다. 둘만의 다음 데이트 완료 시 서운함이 풀린다.
- 셋이 이야기하기: 두 사람 모두 친구 이상일 때, 양쪽의 오늘 대화 기회를 쓰고 절반의 반복 보상을 적용한다. 질투 판정을 만들지 않는다.
- 저장: 선물 재고·내역·간격, 데이트 중 이미 낸 비용과 선택, 앨범, 질투·목격·인사 기록을 저장한다. 중간 재개 시 비용·보상이 다시 적용되지 않는 것을 검사했다.

## 미술

`imagegen`으로 노래방을 제작했다. 첫 사실적 시안은 채택하지 않았다. 새로 생성한 선화와 셀 채색 시안을 `assets/campus-v2/karaoke-v1.png`에 복사하고 실제 데이트에 연결했다. 기존 일부 배경과 인물별 소품 고정 자세·표정은 추가 제작 대상이다.

## 검증

- `node tests/campus-v2.test.mjs`: 20/20.
- `node tests/campus-v2-runtime.test.mjs`: 13/13. 실제 게임 입력 처리에 구입·전달 취소, 중복 클릭, 데이트 전후 자원, 선택 중 저장·재개, 필수 사건 보호, 그룹 대화를 포함한다.
- `node tests/campus-v2-assets.test.mjs`: 26개 실제 자원, 두 진입점·스크립트 순서, 일반 데이트 60개 조합의 배경·두 선택지 구조를 확인한다.
- Safari: 격리된 QA 세션에서 가게 구입(150,000→142,000원 / 피크 1→2개), 다은과의 만남, 노래방 약속(16,000원 / 기력 15), 두 선택지, 밤 복귀, 앨범의 날짜·장소·선택 문장을 실제로 확인했다. 화면은 도구 결과의 스크린샷으로 검토했다.
- QA 세션은 `node tests/create-campus-social-preview.mjs`로 재생성한다. `qa/campus-v2/social-preview.html`은 실제 런타임을 사용하되 `localStorage`를 탭 안의 임시 메모리로 대체한다. 플레이어 저장을 읽거나 덮어쓰지 않는다. 따라서 이 화면 검사를 브라우저의 영구 저장·네이티브 파일 가져오기 검증으로 해석하지 않는다.
- Windows EXE, 모든 해상도, 전체 연간 루트·결말 검증은 이번 변경에서 수행하지 않았다.
