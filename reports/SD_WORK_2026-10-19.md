# SD 수련의 작업 노트 · 2026-10-19

일하기를 시작하면 휴대폰 안에서 SD 수련이 해당 작업을 소개한다. 원래 일하기의 주체와 경제 규칙은 유지하고, SD 수련을 작업 내용을 보여주는 캐릭터로 사용한다.

| 일 | 표시하는 작업 | 연출 |
| --- | --- | --- |
| 카페 아르바이트 | 주문 확인 → 커피 추출 → 음료 전달 | 커피머신·컵·움직이는 김, 캐릭터의 작은 움직임 |
| 영상 편집 외주 | 장면 선택 → 자막·음악 → 내보내기 | 편집 모니터·타임라인 커서, 타이핑 리듬 |
| 행사 운영 보조 | 안내판 → 물품 정리 → 현장 점검 | 안내판·가랜드·상자, 물품 정리 리듬 |

작업 한 건당 3단계, 약 3.3초. 마지막에는 완료한 일의 보수를 표시한다. 결과 바로 보기와 닫기·홈 이동이 가능하다. 개별 예약 일정은 결과에서 일정 화면으로 돌아가며, 일괄 실행은 실제 완료한 작업만 순서대로 표시한다. 움직임 줄이기 설정 또는 OS의 reduced-motion에서는 정적인 완료 화면을 즉시 표시한다.

일의 보수·시간·기력은 기존 엔진으로 한 번 처리하고 자동 저장한 뒤 연출을 표시한다. 연출은 게임 상태를 수정하지 않는다. 건너뛰기·닫기·새로고침으로 보수를 다시 받지 않으며, 다른 화면이나 홈으로 이동하면 타이머를 해제한다.

## 아트와 소스

- 원화 참조: 기존 프로젝트의 `assets/characters/sulien.png`.
- 생성 방식: 내장 **image_gen** 도구, 투명 배경 요청. 외부 API나 CLI는 사용하지 않았다.
- 완성 에셋: [sulien-sd-work.png](../assets/characters/sulien-sd-work.png), 1024×1536 PNG, 약 1.87 MB. ARGB와 모서리/외곽 알파 0을 확인했다. 생성된 파일을 변경 없이 프로젝트에 복사했다.
- [최종 생성 프롬프트](../assets/characters/sulien-sd-work.prompt.txt).
- `src/work.js`: SD 이미지·직업별 로컬 SVG 소품·단계 표시·타이머 수명 관리. `src/work.css`: 캐릭터/소품 움직임과 휴대폰 내부 레이아웃. 프레임별로 다른 그림을 그린 스프라이트 애니메이션은 아니며, 하나의 SD 컷아웃과 소품을 CSS로 움직인다.
- 저장 형식과 게임 엔진 규칙 변경 없음. 기존 원화와 사용자 변경 사항 유지.
