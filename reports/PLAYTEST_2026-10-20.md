## 발견과 조치

1. **휴대폰 지도 방향 버튼이 작아짐 — 수정 완료.** 공통 앱 버튼의 `min-width:0`이 지도 조작 버튼에도 적용됐다. 방향 버튼에 최소 44×44px을 보장했다. 세 해상도의 레이아웃 검사와 실제 방향키 한 칸 이동 검사를 통과했다. 배포 폴더의 스타일과 원본 해시도 일치한다.
2. **테스트 간 저장 데이터 오염 — 테스트 환경 수정.** 한 브라우저 프로필에서 회차 보너스가 다음 테스트에 남아 초기 자금/이야기 검사가 실패했다. 각 최상위 테스트 페이지 진입 때만 저장을 초기화해 분리했다. 한 테스트 내 iframe 새로고침은 저장을 유지한다. 이야기·패션·인트로를 재검사해 통과했다.
3. **이전 UI를 전제로 한 검사 — 테스트 경로 수정.** 예산은 휴대폰 앱으로 진입하는지 확인하도록 변경했고, 새 게임 인트로와 첫 이야기 버튼의 키보드 포커스 순서도 반영했다. PowerShell 테스트에는 UTF-8 BOM을 추가해 한글 버튼 비교가 Windows PowerShell에서 깨지지 않게 했다.
4. **검사 결과에 오래된 날짜/환경 오류가 기록됨 — 보고 코드 수정.** Core 보고서는 실행 날짜로 저장하고, 브라우저 검사 결과는 별도 보고서를 참조하도록 바꿨다. 20일자 로직 검사를 다시 실행했다.

## 범위와 한계

사용자 저장을 건드리지 않도록 Chrome은 별도 프로필, EXE 시도는 임시 WebView2 사용자 데이터 폴더를 지정했다. WebView2 폴더·디버깅 인자 분리 방식은 [Microsoft CreateAsync 문서](https://learn.microsoft.com/en-us/dotnet/api/microsoft.web.webview2.core.corewebview2environment.createasync?view=webview2-dotnet-1.0.4022.49)의 환경 변수 규칙을 따랐다. 임시 폴더로 시작한 EXE가 디버깅 대상을 제공하지 않아 두 차례 연결 대기 후 종료했다. 원인은 확정하지 않았으며, EXE가 정상 플레이된다고 판정하지 않는다.

모바일은 기존 PC 전용 범위에 포함하지 않았다. Windows 네이티브 파일 선택 대화상자, EXE 전체화면 전환, 실기기 성능·장시간 플레이는 미검증이다. Chrome 파일 다운로드와 DOM 파일 입력으로 검증한 저장 왕복을 Windows 네이티브 대화상자 검사로 간주하지 않는다.

## 재실행

### EXE 배포본 갱신 (2026-10-20)

휴대폰 16개 앱, 메시지 화면, SD 수련 일하기 연출과 지도 버튼 수정을 포함해 Windows x64 self-contained Release를 다시 publish했다. 임시 배포 디렉터리에서 원본 게임 파일 597개의 SHA-256을 대조한 뒤 기존 `dist/AquaLuna`에 반영했다. EXE를 포함한 배포 파일 598개도 임시 빌드와 모두 일치한다. 전체 크기는 438,791,080바이트(약 418 MiB)다. [패키징 검증 기록](../qa/exe-package-2026-10-20.json)에 EXE 해시를 기록했다.

실행 파일은 `dist/AquaLuna/AquaLuna.exe`이며 옆의 `game` 폴더도 함께 유지해야 한다. 사용자 저장 폴더는 변경하지 않았다. 새 EXE에 대해 숨김 실행과 창 표시 실행을 각각 시도했지만 WebView2 자동 연결은 여전히 시간 초과였다. 창 표시 시 프로세스 응답과 게임 창 제목은 확인했으나 내부 게임 화면 검사는 완료하지 못했다. 위 브라우저 검사 통과와 이 제한은 구분한다.

```powershell
node tests/run-core.mjs --date=2026-10-20
node tests/phone-browser.mjs
powershell -NoProfile -ExecutionPolicy Bypass -File tests/run-story-check.ps1 -ContinueOnFailure
powershell -NoProfile -ExecutionPolicy Bypass -File tests/browser-check.ps1
dotnet build launcher/AquaLuna.csproj -c Release --no-restore
node tests/desktop-smoke.mjs
```

Node가 PATH에 없으면 설치된 런타임의 절대 경로로 실행한다. 기본 `run-story-check.ps1` 목록에는 인트로가 없으므로 인트로는 `-Tests intro`로 별도 검사한다. `desktop-smoke.mjs`는 현재 환경에서 연결에 실패한 검사를 재현하는 명령이다.
