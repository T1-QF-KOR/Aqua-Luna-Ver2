# 05. 하루 생활과 캠퍼스

## 하루의 기본 흐름

내 계획 확인 → 장소와 활동 선택 → 개인 결과 또는 만남 → 기록·남은 시간 확인 → 다음 활동 또는 귀가.

플레이어에게는 돈을 버는 일, 자신의 노래, 친구와의 관계, 휴식이 모두 필요하다. 모든 활동의 설명을 ‘수련을 위해’로 쓰지 않는다. 수련을 만나지 않은 날에도 내 기록이 남고 내일 할 일이 생긴다.

## 시간 규칙의 권장 기준

| 항목 | 첫 검증안 | 현재 기반 / 주의 |
| --- | --- | --- |
| 하루 자유 시간 | 기존 3칸 유지 | 수업·왕복 통학을 제외한 추상 시간 |
| 지도·일정·기록 보기 | 무료 | UI를 여는 행동에 비용을 붙이지 않음 |
| 장소 고르기 | 무료 | 활동 확정 전 취소 가능 |
| 새 개인 활동 | 시작 확정 시 1칸 | 기력은 활동별 가안. 완료에 재차 차감하지 않음 |
| 첫 인사·연락처 등 주요 이야기 | 별도 비용 없는 사건으로 우선 검증 | 기존 이야기 규칙과 맞춤. 조건은 사건·날짜로 제어 |
| 기존 알바·데이트·휴식 | 현재 비용·요일 제약 유지 | 새 시스템 검증과 동시에 경제를 전면 재조정하지 않음 |
| 대화·선물 | 기존 일일 제한 재사용, 만남/교환 조건 보강 | 새로운 호감 획득 무한 반복을 만들지 않음 |
| 밤/다음 날 | 사용자가 종료를 선택 | 실제 시계·미접속 기간 사용 안 함 |

지도에서 걸어간 것과 선택한 활동의 시간을 이중 차감하지 않는다. 미래에 이동 비용을 추가하면 모든 장소의 표기·일정·기존 코스 비용을 함께 재설계한다.

## 장소 구성

장소 여섯 곳은 **기획상 기능**이다. 독서 공간·게시판 등에 적합한 실제 배경의 존재와 연출 방식은 에셋 검수 후 정한다. 기존 연습실 그림을 이름만 바꿔 도서관으로 확정하지 않는다.

| 장소 | 혼자 할 일 | 수련·조연과의 접점 | 장기 결과 |
| --- | --- | --- | --- |
| 전공 강의실 | 시간표·과제 확인, 짧은 복습 | 첫 인사, 과제 짝 | 과제 단서, 수업 기억 |
| 연습실 | 개인 녹음·연습 계획 | 공동 연습, 서로 듣기 | 내 데모·공동 테이크 |
| 학생식당 | 메뉴 살피기·휴식성 짧은 사건 | 재회, 공강 점심 | 연락처·일상 대화 |
| 동네 카페 | 근무·음료 메모·게시판 확인 | 근무 중 인사, 짧은 약속 | 수입·취향·일터 이야기 |
| 강변 산책길 | 사진·새 길·풍경 기록 | 귀가 전 산책 | 사진·코스 발견·추억 |
| 학과 게시판/자료 공간 | 행사 정보·부탁·연습 자료 | 하윤과 조연의 일상 | 행사 일정·짧은 퀘스트 |

처음에는 3곳을 보여 주고 접점이 생길 때 다른 장소를 소개하는 안을 권한다. 잠긴 장소를 수십 개 나열하지 않는다. 기존 탐방 48곳은 ‘함께 가는 외출’ 목록으로 유지하고 일상 장소와 용도를 분리한다.

## 수련이 있는 장소와 일정

관계 전에는 ‘수련 위치 추적’처럼 모든 장소에 인물 아이콘을 표시하지 않는다. 첫 수업은 수업 일정으로 안내한다. 이후에는 직접 들은 연습 일정이나 합의한 약속만 지도에 표시한다. 랜덤 출현만 기다려야 하는 필수 사건은 피한다.

수련은 수업·근무·연습을 한다. 플레이어와 만나는 사건을 읽을 때만 동행 상태로 전환한다. 플레이어의 근무가 끝난 뒤 수련에게 연락이 왔다면 메시지 화면으로 보여 주며, 같은 일터에 서 있는 대면 장면으로 바꾸지 않는다.

## 개인 성장과 음악

현재 지식·체력·감수성을 그대로 활용하는 안을 권한다. 지식은 자료 정리와 연습 준비, 체력은 긴 동선과 컨디션, 감수성은 감상·가사 해석의 다른 접근을 만든다. 실제 노래 실력이나 사람의 가치를 한 숫자로 환산하는 설명은 피한다.

개인 목표에는 결과물을 둔다. 예: 첫 개인 녹음 → 다시 들으며 한 곳 표시 → 다른 해석으로 재녹음 → 수련에게 들려줄지 선택. 단순히 능력치 버튼을 여러 번 누르는 것과 구분한다. 완성품을 공유하지 않고 나의 노트에만 남겨도 유효하다.

## 경제와 알바

기존 카페·편집 외주·행사 보조의 수입과 요일 규칙을 우선 유지한다. 새 활동 보상은 돈보다 결과물·기록·능력의 다른 사용처에 둔다. 필수 첫 인사와 기본 관계 진행에는 고가 의상·공연 구매를 요구하지 않는다.

카페 미니게임은 기존 근무의 선택 체험으로 붙이는 안이다. 일하기 정산을 끝낸 뒤 미니게임을 다시 열어 임금을 중복 지급하지 않는다. 성과 보너스가 필요하면 기존 기본임금과 별개인 작은 보너스로 설계하고, 첫 검증에서는 지급하지 않는다.

## 첫 주의 일정 예시

첫날에는 첫 인사와 개인 활동, 둘째 날에는 연락처와 자신의 일, 셋째 날에는 곡 공유, 이후에는 공동 연습과 짧은 산책을 연결할 수 있다. 하루에 모든 관계 사건을 읽도록 요구하지 않는다. 미뤄 둔 첫 인사·연락처는 가능한 다음 수업·재회로 이어진다. 정확한 7일 예시는 08 문서에 있다.

시험·공연·축제는 뒤 단계에서 하루의 분위기와 선택 가능 활동을 바꾸는 확장이다. 초반에는 연애·음악·일상의 관계를 먼저 이해할 수 있게 한다.
