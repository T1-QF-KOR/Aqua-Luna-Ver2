# 스팀 미연시 레퍼런스 기반 제작 가이드

작성일: 2026-10-27 · 대상: Aqua Luna Ver2 · 상태: **조사 기반 제작 제안 / 게임 코드 미반영**

**플레이어의 대학 생활에서 시작해 수련을 처음 만나고, 각자의 일상과 함께한 경험을 통해 관계를 발전시키는 게임**을 만들기 위한 문서 묶음이다. 스팀 공개 자료로 확인한 기능, 그 기능의 설계상 장점, Aqua Luna에 맞게 바꾼 창작 제안을 분리했다.

사용자가 정한 방향은 플레이어 시점의 시작, 수련과의 첫 만남부터 관계 형성, 스팀 연애 시뮬레이션을 참고한 즐길거리 확대다. 이 폴더의 세부 수치·예시 대본·활동·제작 순서는 그 방향을 구체화한 제안이다. 문서 작성 요청은 게임 코드 구현 요청으로 해석하지 않는다.

## 자료의 상태를 읽는 법

- **확인:** Steam의 개발사·배급사 소개 또는 이번에 읽은 저장소 소스에서 확인했다. 플레이 테스트 완료라는 의미는 아니다.
- **장점 해석:** 확인한 구조가 어떤 경험에 도움을 줄 수 있는지 분석한 것이다. 실제 재미·완성도·판매 성과의 검증 결과가 아니다.
- **적용 제안:** Aqua Luna용 창작안. 원작에 동일한 기능이 있다는 뜻이 아니다.
- **미정:** 구현 전에 통일해야 할 설정이나 아직 검증하지 않은 값이다.
- **P0/P1/P2:** 각각 핵심 전환, 핵심을 풍성하게 하는 확장, 충분한 검증 뒤의 확장이다. 전체 항목을 한 번에 제작하라는 뜻이 아니다.

## 제작의 중심 약속

1. 수련을 만나기 전에도 플레이어의 하루에 목적과 선택이 있다.
2. 수련을 아는 정도와 장면에 실제로 함께 있는지는 따로 다룬다.
3. 개인 활동은 능력이나 기록을 남기고, 일부 결과가 다음 만남의 화제가 된다.
4. 관계는 수치와 함께 사건·대화·약속으로 드러난다. 선물만 반복해서 친밀한 장면을 건너뛰지 않는다.
5. 수련에게도 수업·근무·연습과 자기 결정권이 있다. 관계의 진전은 서로의 응답으로 표현한다.
6. 연인이 되기 외에 우정·보류도 의미 있는 선택으로 다룬다.
7. 기존에 존재하는 수집·일정·데이트·체험 시스템을 먼저 연결한다. 기능 수를 늘리는 것만으로 재미가 늘었다고 판단하지 않는다.

## 예시 진행의 한 줄

내 시간표 확인 → 혼자 연습 → 첫 수업에서 수련과 인사 → 다음 만남에서 연락처 교환 → 개인 활동의 결과를 공유 → 짧은 약속 → 서로 먼저 찾는 사이 → 마음 확인.

첫 검증 범위는 **일주일 분량의 첫 만남과 관계 진입, 개인 활동 두 가지, 짧은 외출 한 가지**다. 연간 시나리오·기존 탐방 전체 재연결은 이 흐름이 자연스러운지 확인한 뒤 진행한다. 상세 수량은 09 문서를 기준으로 한다.
