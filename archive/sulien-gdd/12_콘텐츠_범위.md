## 현재 콘텐츠 집계

| 구분 | 수량 | 집계 의미 |

## 플레이 완료와 개발 완료의 구분

| 도달점 | 조건 |
| --- | --- |
| 기본 관계 후일담 | 연인 또는 친구 선택 후 `너와 나란한 하루` 완료 |
| 과거편 마지막 이야기 | 48곳 방문, 테마 후속 24편, `문을 두드리기 전` 완료 |
| 체험 완성 목표 | 선택형 퍼즐 576판 완성. 이야기 완료와 별도 |
| 출시 준비 | 장기 재미·시간·밸런스·대상 기기·접근성 등을 검증하고 남은 출시 범위 결정 필요 |

**30시간 이상은 목표이며 달성 판정이 아니다.** 기존 보고서의 대본 감사는 전체 분기 문장을 합산한 것이고, 생성 퍼즐 수 역시 플레이시간을 보장하지 않는다. 힌트 사용·숙련도·반복 피로를 포함한 실제 플레이 기록으로 평가해야 한다.

기존 검증 기록에는 양쪽 관계 경로, 48곳 탐방, 마지막 이야기, 576판 해결 가능성, 저장과 UI 검사가 보고되어 있다. 이는 이전 작업의 결과이며 이번 GDD 작성에서 다시 실행한 결과가 아니다. 실제 휴대전화·Safari/Firefox·음향 청취·스크린리더·장기 사람 플레이 검증은 남아 있다.

현재 범위 밖: 다중 공략 인물, 회사·팬덤·방송 운영, 실시간 달력, 수련의 독립 생활 시뮬레이션, 온라인 멀티플레이, 실제 결제. 해당 기능을 추가하려면 별도 기획이 필요하다.
